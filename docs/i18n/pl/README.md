# Thomas Vincent

Tworzę narzędzia do obsługi infrastruktury, automatyzacji przepływów pracy w macOS oraz ułatwiania analizy zachowania systemów. Moja praca obejmuje Go, Pythona, Rusta, PHP, TypeScript oraz konfigurację infrastruktury.

## Wybrane projekty

| Projekt | Co zapewnia |
| --- | --- |
| [Infrastruktura runnerów GitHub](https://github.com/somethingwithproof/github-runners-infra) | Kontroler w Go dla jednorazowych runnerów przypisanych do repozytorium w DigitalOcean, AWS, Google Cloud i Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Statyczna przeglądarka danych o rozproszonej energetyce słonecznej w Kalifornii z metodologią oraz jasno określonymi ograniczeniami pokrycia i modelowania | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Przepływy pracy w macOS do szybkiego przechwytywania zadań w aplikacjach produktywnościowych z użyciem AppleScript, Automator i Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Interaktywne narzędzie CLI w języku Rust do tworzenia komunikatów zgodnych z Conventional Commit | |
| [Sprawdzanie ceny Bitcoina](https://github.com/somethingwithproof/check_bitcoin_price) | Wtyczka dla Nagios/Icinga z progami cenowymi, opcjonalnym sprawdzaniem aktualności notowań i ograniczoną liczbą ponowień żądań | |

Plik README, kod źródłowy oraz wyniki przepływów pracy każdego projektu określają jego bieżący zakres. Funkcje eksperymentalne i integracje specyficzne dla platform wymagają osobnej walidacji; odznaka nie stanowi deklaracji gotowości produkcyjnej.

## Inne prace

- **Monitoring sieci:** [Kadupul](https://github.com/kadupulhq/kadupul), projekt monitoringu wywodzący się z Cacti w organizacji `kadupulhq`.
- **Konfiguracja infrastruktury:** automatyzacja dla [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) i [zapory sieciowej hosta](https://github.com/somethingwithproof/ansible-collection-firewall), z ograniczeniami specyficznymi dla implementacji udokumentowanymi w każdym repozytorium.
- **Integracja z macOS:** [Serwery MCP](https://github.com/somethingwithproof/mcp-servers), skonsolidowane repozytorium integracji aplikacji.
- **Narzędzia CI:** [Foundry](https://github.com/somethingwithproof/foundry), oparty na profilach runner poleceń z planowaniem zależności i logami wykonania.

Zajmuję się również przepływami pracy nad materiałem dowodowym w genealogii oraz badaniami danych rynkowych. Te obszary zainteresowań nie oznaczają certyfikowanych wniosków badawczych, zweryfikowanych wyników handlowych ani publicznej dostępności każdego repozytorium badawczego.

## Zgłaszanie problemów bezpieczeństwa

Postępuj zgodnie z plikiem `SECURITY.md` danego repozytorium i jego skonfigurowanym prywatnym kanałem zgłaszania. W przypadku projektów nadrzędnych korzystaj z ich własnego procesu ujawniania podatności. Unikaj publikowania w otwartych zgłoszeniach nieujawnionych szczegółów podatności oraz poświadczeń.
