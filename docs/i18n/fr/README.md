# Thomas Vincent

Je conçois des outils pour exploiter l'infrastructure, automatiser des workflows macOS et faciliter l'inspection du comportement des systèmes. Mon travail couvre Go, Python, Rust, PHP, TypeScript et la configuration d'infrastructure.

## Projets sélectionnés

| Projet | Ce qu'il propose |
| --- | --- |
| [Infrastructure de runners GitHub](https://github.com/somethingwithproof/github-runners-infra) | Un contrôleur Go pour des runners à tâche unique et à portée de dépôt sur DigitalOcean, AWS, Google Cloud et Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Un explorateur statique des données solaires distribuées de Californie, accompagné d'une méthodologie et de limites explicites de couverture et de modélisation | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Des workflows de capture macOS pour des applications de productivité, utilisant AppleScript, Automator et Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Une CLI Rust interactive pour rédiger des messages Conventional Commits | |
| [Vérification du prix du Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Un plugin Nagios/Icinga doté de seuils de prix, de vérifications optionnelles de fraîcheur des cotations et de tentatives de requête bornées | |

Le README, le code source et les résultats des workflows de chaque projet définissent son périmètre actuel. Les fonctionnalités expérimentales et les intégrations propres à une plateforme nécessitent leur propre validation ; un badge ne constitue pas une garantie d'aptitude à la production.

## Autres travaux

- **Supervision réseau :** [Kadupul](https://github.com/kadupulhq/kadupul), un projet de supervision dérivé de Cacti au sein de l'organisation `kadupulhq`.
- **Configuration d'infrastructure :** automatisation [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) et [pare-feu hôte](https://github.com/somethingwithproof/ansible-collection-firewall), avec des limites propres à chaque implémentation documentées dans chaque dépôt.
- **Intégration macOS :** [serveurs MCP](https://github.com/somethingwithproof/mcp-servers), le dépôt consolidé pour les intégrations applicatives.
- **Outillage CI :** [Foundry](https://github.com/somethingwithproof/foundry), un exécuteur de commandes basé sur des profils avec planification des dépendances et journaux d'exécution.

Je travaille également sur des workflows de preuves généalogiques et la recherche sur les données de marché. Ces domaines d'intérêt n'impliquent ni conclusions de recherche certifiées, ni performances de trading vérifiées, ni disponibilité publique de chaque dépôt de recherche.

## Signalements de sécurité

Suivez le fichier `SECURITY.md` du dépôt concerné ainsi que son canal de signalement privé configuré. Pour les projets en amont, utilisez le processus de divulgation du projet concerné. Évitez les tickets publics contenant des détails de vulnérabilités non divulguées ou des identifiants.
