# Thomas Vincent

Ngakha amathuluzi okusebenzisa ingqalasizinda, ukwenza izinhlelo zomsebenzi ze-macOS zizenzakalele, nokwenza ukuziphatha kwesistimu kube lula ukukuhlola. Umsebenzi wami uhlanganisa i-Go, i-Python, i-Rust, i-PHP, i-TypeScript, nokulungiswa kwengqalasizinda.

## Amaphrojekthi akhethiwe

| Iphrojekthi | Okunikezwayo |
| --- | --- |
| [Ingqalasizinda yama-runner e-GitHub](https://github.com/somethingwithproof/github-runners-infra) | I-controller ye-Go yama-runner asebenza ngomsebenzi owodwa enqolobaneni ethile ku-DigitalOcean, ku-AWS, ku-Google Cloud, naku-Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Isihloli esimile sedatha yamandla elanga asabalaliswayo e-California, esinendlela yokusebenza nemikhawulo ecacile yokufinyelela/yokwakha amamodeli | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Izinhlelo zomsebenzi zokuthwebula ze-macOS zezinhlelo zokusebenza zokukhiqiza, ezisebenzisa i-AppleScript, i-Automator, ne-Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | I-CLI ye-Rust esebenzisanayo yokwakha imilayezo ye-Conventional Commit | |
| [Ukuhlolwa kwentengo ye-Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | I-plugin ye-Nagios/Icinga enemikhawulo yentengo, ukuhlolwa okuzikhethelayo kobusha bamanani, nokuzama kabusha kwezicelo okunomkhawulo | |

I-README yephrojekthi ngayinye, umthombo wekhodi, nemiphumela yohlelo lomsebenzi kuchaza ububanzi bayo bamanje. Izici zokuhlola nokuhlanganiswa okuqondene nepulatifomu kudinga ukuqinisekiswa okuzimele; ibheji akusona isiqinisekiso sokulungela ukukhiqiza.

## Omunye umsebenzi

- **Ukuqapha inethiwekhi:** I-[Kadupul](https://github.com/kadupulhq/kadupul), iphrojekthi yokuqapha esuselwe ku-Cacti ngaphansi kwenhlangano ye-`kadupulhq`.
- **Ukulungiswa kwengqalasizinda:** Ukuzenzakalela kwe-[MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), kwe-[WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), kanye [ne-firewall yomshini oyisikhungo](https://github.com/somethingwithproof/ansible-collection-firewall), okunemikhawulo eqondene nokusebenza ebhalwe enqolobaneni ngayinye.
- **Ukuhlanganiswa kwe-macOS:** [Amaseva e-MCP](https://github.com/somethingwithproof/mcp-servers), inqolobane ehlanganisiwe yokuhlanganiswa kwezinhlelo zokusebenza.
- **Amathuluzi e-CI:** I-[Foundry](https://github.com/somethingwithproof/foundry), ithuluzi lokusebenzisa imiyalo elisekelwe kumaphrofayela elinokuhlela izidingo namalogi okusebenza.

Ngiphinde ngisebenze ezinhlelweni zomsebenzi zobufakazi bozalo nocwaningo lwedatha yemakethe. Lezo zintshisekelo azisho iziphetho zocwaningo eziqinisekisiwe, ukusebenza kokuhweba okuqinisekisiwe, noma ukutholakala esidlangalaleni kwazo zonke izinqolobane zocwaningo.

## Imibiko yokuvikeleka

Landela i-`SECURITY.md` yenqolobane ethintekile kanye nesiteshi sayo sangasese sokubika esilungiselelwe. Kumaphrojekthi e-upstream, sebenzisa inqubo yokudalula yaleyo phrojekthi ye-upstream. Gwema izinkinga zomphakathi eziqukethe imininingwane engakadalulwa yobuthaka bokuvikeleka noma imininingwane yokungena.
