# Thomas Vincent

உள்கட்டமைப்பை இயக்குவதற்கும், macOS பணிப்பாய்வுகளைத் தானியக்கமாக்குவதற்கும், கணினி நடத்தையை எளிதாக ஆய்வு செய்வதற்கும் தேவையான கருவிகளை உருவாக்குகிறேன். எனது பணி Go, Python, Rust, PHP, TypeScript மற்றும் உள்கட்டமைப்புக் கட்டமைப்பு ஆகிய துறைகளில் பரவியுள்ளது.

ஒவ்வொரு திட்டத்தின் README, மூலக் குறியீடு மற்றும் பணிப்பாய்வு முடிவுகள் அதன் தற்போதைய வரம்பை வரையறுக்கின்றன. சோதனை அம்சங்களுக்கும் தள-குறிப்பிட்ட ஒருங்கிணைப்புகளுக்கும் அவற்றின் சொந்த சரிபார்ப்பு தேவை; ஒரு சின்னம் (badge) தயாரிப்பு-தயார்நிலைக்கான உறுதிமொழி அல்ல.

## பிற பணிகள்

- **பிணையக் கண்காணிப்பு:** [Kadupul](https://github.com/kadupulhq/kadupul), இது `kadupulhq` அமைப்பின் கீழ் உள்ள Cacti-அடிப்படையிலான கண்காணிப்புத் திட்டம்.
- **உள்கட்டமைப்புக் கட்டமைப்பு:** [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), மற்றும் [ஹோஸ்ட் ஃபயர்வால்](https://github.com/somethingwithproof/ansible-collection-firewall) தானியக்கம்; செயல்படுத்தல் சார்ந்த எல்லைகள் ஒவ்வொரு களஞ்சியத்திலும் ஆவணப்படுத்தப்பட்டுள்ளன.
- **macOS ஒருங்கிணைப்பு:** [MCP சேவையகங்கள்](https://github.com/somethingwithproof/mcp-servers), பயன்பாட்டு ஒருங்கிணைப்புகளுக்கான ஒருங்கிணைந்த களஞ்சியம்.
- **CI கருவிகள்:** [Foundry](https://github.com/somethingwithproof/foundry), சார்புத் திட்டமிடல் மற்றும் இயக்கப் பதிவுகளுடன் கூடிய சுயவிவர-அடிப்படையிலான கட்டளை இயக்கி.

வம்சாவளிச் சான்று பணிப்பாய்வுகள் மற்றும் சந்தைத் தரவு ஆராய்ச்சியிலும் நான் பணியாற்றுகிறேன். இந்த ஆர்வங்கள் சான்றளிக்கப்பட்ட ஆராய்ச்சி முடிவுகளையோ, சரிபார்க்கப்பட்ட வர்த்தகச் செயல்திறனையோ அல்லது ஒவ்வொரு ஆராய்ச்சிக் களஞ்சியமும் பொதுவில் கிடைப்பதையோ குறிக்காது.

## பாதுகாப்பு அறிக்கைகள்

பாதிக்கப்பட்ட களஞ்சியத்தின் `SECURITY.md` மற்றும் அதன் கட்டமைக்கப்பட்ட தனிப்பட்ட அறிக்கையிடல் வழியைப் பின்பற்றவும். மேல்நிலைத் திட்டங்களுக்கு, அந்த மேல்நிலைத் திட்டத்தின் வெளிப்படுத்தல் செயல்முறையைப் பயன்படுத்தவும். வெளிப்படுத்தப்படாத பாதுகாப்புக் குறைபாடு விவரங்கள் அல்லது நற்சான்றிதழ்களைக் கொண்ட பொதுப் புகார்களைத் தவிர்க்கவும்.
