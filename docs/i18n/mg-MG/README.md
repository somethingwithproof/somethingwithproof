# Thomas Vincent

Manamboatra fitaovana ho an'ny fitantanana fotodrafitrasa, fampandehanana ho azy ny fizotran'asa amin'ny macOS, ary fanamorana ny fanaraha-maso ny fihetsiky ny rafitra aho. Mahafaoka ny Go, Python, Rust, PHP, TypeScript, ary fandrindrana fotodrafitrasa ny asako.

## Tetikasa voafantina

| Tetikasa | Izay omeny |
| --- | --- |
| [Fotodrafitrasa GitHub runner](https://github.com/somethingwithproof/github-runners-infra) | Mpibaiko Go ho an'ny runner manokana isaky ny tahiry sy asa tokana amin'ny DigitalOcean, AWS, Google Cloud, ary Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Mpijery tsy miovaova (static explorer) ho an'ny angon-drakitra herin'ny masoandro miparitaka any Kalifornia, miaraka amin'ny fomba fiasa sy fetra mazava momba ny fandrakofana sy ny modely | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Fizotran'asa fanangonan-kevitra amin'ny macOS ho an'ny rindrambaiko fampitomboana vokatra, mampiasa AppleScript, Automator, ary Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Fitaovana CLI Rust ifanakalozana natao hananganana hafatra Conventional Commit | |
| [Fanamarinana ny vidin'ny Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Plugin Nagios/Icinga misy fetram-bidy, fanamarinana tsy voatery ny fahavaozan'ny vidiny, ary famerenana fangatahana voafetra | |

Ny README, ny loharano, ary ny vokatry ny fizotran'asa ao amin'ny tetikasa tsirairay no mamaritra ny sahan'asany ankehitriny. Mila fanamarinana manokana ny endri-javatra andrana sy ny fampidirana manokana isaky ny sehatra; ny marika (badge) dia tsy filazana fahavononana ho an'ny famokarana.

## Asa hafa

- **Fanaraha-maso tambajotra:** [Kadupul](https://github.com/kadupulhq/kadupul), tetikasa fanaraha-maso avy amin'ny Cacti eo ambany fitantanan'ny fikambanana `kadupulhq`.
- **Fandrindrana fotodrafitrasa:** Fampandehanana ho azy ho an'ny [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), ary [aro-afon'ny mpampiantrano](https://github.com/somethingwithproof/ansible-collection-firewall), miaraka amin'ny fetra manokana isaky ny fampiharana voarakitra ao amin'ny tahiry tsirairay.
- **Fampidirana amin'ny macOS:** [Mpizara MCP](https://github.com/somethingwithproof/mcp-servers), ny tahiry mitambatra ho an'ny fampidirana rindrambaiko.
- **Fitaovana CI:** [Foundry](https://github.com/somethingwithproof/foundry), mpandefa baiko mifototra amin'ny mombamomba (profile) miaraka amin'ny fandrindrana fiankinan-doha sy firaketana fampandehanana.

Miasa amin'ny fizotran'asa porofo momba ny tetiarana sy fikarohana angon-drakitry ny tsena ihany koa aho. Ireo mahaliana ahy ireo dia tsy midika ho fehin-kevitra fikarohana voamarina, vokatra ara-barotra voaporofo, na fisian'ny tahiry fikarohana rehetra ho an'ny daholobe.

## Tatitra fiarovana

Araho ny `SECURITY.md` an'ny tahiry voakasika sy ny fantsona fitaterana manokana voarindra ao. Ho an'ny tetikasa loharano ambony (upstream), ampiasao ny dingana fampahafantarana an'ilay tetikasa. Fadio ny olana (issues) ho an'ny daholobe misy antsipirian'ny lesoka tsy mbola nambara na fahazoan-dalana miafina.
