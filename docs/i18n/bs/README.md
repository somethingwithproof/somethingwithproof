# Thomas Vincent

Gradim alate za upravljanje infrastrukturom, automatizaciju macOS tokova rada i lakši pregled ponašanja sistema. Moj rad obuhvata Go, Python, Rust, PHP, TypeScript i konfiguraciju infrastrukture.

## Odabrani projekti

| Projekat | Šta pruža |
| --- | --- |
| [Infrastruktura za GitHub runnere](https://github.com/somethingwithproof/github-runners-infra) | Go kontroler za jednokratne runnere vezane za repozitorij na DigitalOcean, AWS, Google Cloud i Azure platformama | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Statički preglednik podataka o distribuiranoj solarnoj energiji u Kaliforniji s metodologijom i jasno navedenim ograničenjima pokrivenosti i modeliranja | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | macOS tokovi rada za brzo bilježenje zadataka u aplikacijama za produktivnost koristeći AppleScript, Automator i Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Interaktivni Rust CLI alat za sastavljanje Conventional Commit poruka | |
| [Provjera cijene Bitcoina](https://github.com/somethingwithproof/check_bitcoin_price) | Nagios/Icinga dodatak s cjenovnim pragovima, opcionalnim provjerama svježine kotacija i ograničenim brojem ponovnih zahtjeva | |

README datoteka, izvorni kod i rezultati tokova rada svakog projekta definišu njegov trenutni obim. Eksperimentalne mogućnosti i integracije specifične za platformu zahtijevaju vlastitu provjeru; oznaka (badge) ne predstavlja tvrdnju o spremnosti za produkciju.

## Ostali radovi

- **Nadzor mreže:** [Kadupul](https://github.com/kadupulhq/kadupul), projekat za nadzor mreže zasnovan na Cacti platformi u organizaciji `kadupulhq`.
- **Konfiguracija infrastrukture:** automatizacija za [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) i [vatrozid hosta](https://github.com/somethingwithproof/ansible-collection-firewall), sa specifičnim ograničenjima implementacije dokumentovanim u svakom repozitoriju.
- **macOS integracija:** [MCP serveri](https://github.com/somethingwithproof/mcp-servers), objedinjeni repozitorij za integracije aplikacija.
- **CI alati:** [Foundry](https://github.com/somethingwithproof/foundry), pokretač naredbi zasnovan na profilima s planiranjem zavisnosti i zapisnicima izvršavanja.

Također se bavim tokovima rada za genealoške dokaze i istraživanjem tržišnih podataka. Ta interesovanja ne podrazumijevaju certificirane istraživačke zaključke, verificirane rezultate trgovanja niti javnu dostupnost svakog istraživačkog repozitorija.

## Sigurnosni izvještaji

Slijedite datoteku `SECURITY.md` zahvaćenog repozitorija i njegov podešeni privatni kanal za prijavu. Za uzvodne (upstream) projekte koristite njihov postupak otkrivanja ranjivosti. Izbjegavajte javne prijave koje sadrže neobjavljene detalje ranjivosti ili pristupne podatke.
