# Thomas Vincent

ผมสร้างเครื่องมือสำหรับการดูแลปฏิบัติการโครงสร้างพื้นฐาน การทำงานอัตโนมัติในเวิร์กโฟลว์ของ macOS และการทำให้ตรวจสอบพฤติกรรมของระบบได้ง่ายขึ้น งานของผมครอบคลุมภาษา Go, Python, Rust, PHP, TypeScript และการกำหนดค่าโครงสร้างพื้นฐาน

## โปรเจกต์ที่คัดสรร

| โปรเจกต์ | สิ่งที่เครื่องมือนี้ให้บริการ |
| --- | --- |
| [โครงสร้างพื้นฐาน GitHub runner](https://github.com/somethingwithproof/github-runners-infra) | คอนโทรลเลอร์ที่พัฒนาด้วย Go สำหรับ runner แบบจำกัดขอบเขตระดับรีโพซิทอรีและทำงานครั้งละหนึ่งงานบน DigitalOcean, AWS, Google Cloud และ Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | เว็บแอปพลิเคชันแบบสแตติกสำหรับสำรวจข้อมูลพลังงานแสงอาทิตย์แบบกระจายศูนย์ในแคลิฟอร์เนีย พร้อมระบุระเบียบวิธีและข้อจำกัดด้านความครอบคลุม/แบบจำลองไว้อย่างชัดเจน | |

ขอบเขตปัจจุบันของแต่ละโปรเจกต์กำหนดโดยไฟล์ README ซอร์สโค้ด และผลลัพธ์ของเวิร์กโฟลว์ในโปรเจกต์นั้น ฟีเจอร์ทดลองและการเชื่อมต่อเฉพาะแพลตฟอร์มจำเป็นต้องผ่านการตรวจสอบแยกต่างหาก และแบดจ์ไม่ได้เป็นการรับประกันความพร้อมสำหรับการใช้งานจริงในสภาพแวดล้อมการผลิต

## ผลงานอื่น ๆ

- **การมอนิเตอร์เครือข่าย:** [Kadupul](https://github.com/kadupulhq/kadupul) โปรเจกต์มอนิเตอร์ที่ต่อยอดมาจาก Cacti ภายใต้องค์กร `kadupulhq`
- **การกำหนดค่าโครงสร้างพื้นฐาน:** ระบบอัตโนมัติสำหรับ [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) และ[ไฟร์วอลล์ของโฮสต์](https://github.com/somethingwithproof/ansible-collection-firewall) โดยมีการระบุข้อจำกัดเฉพาะของการพัฒนาไว้ในแต่ละรีโพซิทอรี
- **การเชื่อมต่อกับ macOS:** [เซิร์ฟเวอร์ MCP](https://github.com/somethingwithproof/mcp-servers) รีโพซิทอรีศูนย์รวมสำหรับการเชื่อมต่อกับแอปพลิเคชันต่าง ๆ
- **เครื่องมือ CI:** [Foundry](https://github.com/somethingwithproof/foundry) ตัวรันคำสั่งแบบอิงโปรไฟล์พร้อมการวางแผนลำดับดีเพนเดนซีและบันทึกการทำงาน

นอกจากนี้ผมยังทำงานเกี่ยวกับเวิร์กโฟลว์หลักฐานด้านลำดับวงศ์ตระกูลและการวิจัยข้อมูลตลาด ความสนใจเหล่านี้ไม่ได้หมายความว่ามีข้อสรุปการวิจัยที่ได้รับการรับรอง ผลการเทรดที่ผ่านการยืนยัน หรือการเปิดเผยรีโพซิทอรีงานวิจัยทุกชุดต่อสาธารณะ

## การรายงานปัญหาด้านความปลอดภัย

โปรดปฏิบัติตามไฟล์ `SECURITY.md` ของรีโพซิทอรีที่ได้รับผลกระทบและใช้ช่องทางการรายงานแบบส่วนตัวที่กำหนดไว้ สำหรับโปรเจกต์ต้นน้ำให้ใช้กระบวนการเปิดเผยข้อมูลของโปรเจกต์ต้นน้ำนั้น หลีกเลี่ยงการเปิด issue สาธารณะที่มีรายละเอียดช่องโหว่ที่ยังไม่ถูกเปิดเผยหรือข้อมูลรับรอง
