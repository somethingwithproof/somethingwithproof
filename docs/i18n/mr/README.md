# Thomas Vincent

मी पायाभूत सुविधा चालवण्यासाठी, macOS वर्कफ्लो स्वयंचलित करण्यासाठी आणि सिस्टमच्या वर्तनाचे निरीक्षण सुलभ करण्यासाठी साधने तयार करतो. माझे काम Go, Python, Rust, PHP, TypeScript आणि पायाभूत सुविधा कॉन्फिगरेशनमध्ये पसरलेले आहे.

## निवडक प्रकल्प

| प्रकल्प | काय प्रदान करतो |
| --- | --- |
| [GitHub रनर इन्फ्रास्ट्रक्चर](https://github.com/somethingwithproof/github-runners-infra) | DigitalOcean, AWS, Google Cloud आणि Azure वर रिपॉझिटरी-मर्यादित, सिंगल-जॉब रनर्ससाठी Go कंट्रोलर | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | कार्यपद्धती आणि स्पष्ट व्याप्ती/मॉडेलिंग मर्यादांसह कॅलिफोर्नियातील वितरित-सौर डेटासाठी एक स्टॅटिक एक्सप्लोरर | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | AppleScript, Automator आणि Alfred वापरून उत्पादकता अ‍ॅप्लिकेशन्ससाठी macOS कॅप्चर वर्कफ्लो | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Conventional Commit संदेश तयार करण्यासाठी एक संवादात्मक Rust CLI | |
| [Bitcoin किंमत तपासणी](https://github.com/somethingwithproof/check_bitcoin_price) | किंमत मर्यादा, पर्यायी कोट-ताजेपणा तपासण्या आणि मर्यादित विनंती पुनर्प्रयत्नांसह एक Nagios/Icinga प्लगइन | |

प्रत्येक प्रकल्पाचा README, स्रोत आणि वर्कफ्लो निकाल त्याची सध्याची व्याप्ती परिभाषित करतात. प्रायोगिक वैशिष्ट्ये आणि प्लॅटफॉर्म-विशिष्ट एकत्रीकरणांना त्यांच्या स्वतःच्या पडताळणीची आवश्यकता असते; बॅज म्हणजे प्रोडक्शन-सज्जतेचा दावा नाही.

## इतर कामे

- **नेटवर्क मॉनिटरिंग:** [Kadupul](https://github.com/kadupulhq/kadupul), `kadupulhq` संस्थेअंतर्गत Cacti-आधारित मॉनिटरिंग प्रकल्प.
- **पायाभूत सुविधा कॉन्फिगरेशन:** [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), आणि [होस्ट फायरवॉल](https://github.com/somethingwithproof/ansible-collection-firewall) ऑटोमेशन, प्रत्येक रिपॉझिटरीमध्ये अंमलबजावणी-विशिष्ट मर्यादांचे दस्तऐवजीकरण केलेले आहे.
- **macOS एकत्रीकरण:** [MCP सर्व्हर्स](https://github.com/somethingwithproof/mcp-servers), अ‍ॅप्लिकेशन एकत्रीकरणासाठी एकत्रित रिपॉझिटरी.
- **CI साधने:** [Foundry](https://github.com/somethingwithproof/foundry), अवलंबन नियोजन आणि अंमलबजावणी लॉग्ससह प्रोफाइल-आधारित कमांड रनर.

मी वंशावळ पुराव्यांचे वर्कफ्लो आणि मार्केट-डेटा संशोधनावरही काम करतो. या आवडींचा अर्थ प्रमाणित संशोधन निष्कर्ष, सत्यापित ट्रेडिंग कामगिरी किंवा प्रत्येक संशोधन रिपॉझिटरीची सार्वजनिक उपलब्धता असा होत नाही.

## सुरक्षा अहवाल

प्रभावित रिपॉझिटरीची `SECURITY.md` फाइल आणि तिचे कॉन्फिगर केलेले खाजगी अहवाल चॅनेल वापरा. अपस्ट्रीम प्रकल्पांसाठी, संबंधित अपस्ट्रीम प्रकल्पाची प्रकटीकरण प्रक्रिया वापरा. अप्रकाशित सुरक्षा त्रुटींचे तपशील किंवा क्रेडेंशियल्स असलेले सार्वजनिक इश्यू टाळा.
