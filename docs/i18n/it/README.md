# Thomas Vincent

Realizzo strumenti per gestire infrastrutture, automatizzare workflow su macOS e rendere più semplice l'ispezione del comportamento dei sistemi. Il mio lavoro spazia tra Go, Python, Rust, PHP, TypeScript e configurazione di infrastrutture.

## Progetti selezionati

| Progetto | Cosa offre |
| --- | --- |
| [Infrastruttura per runner GitHub](https://github.com/somethingwithproof/github-runners-infra) | Un controller Go per runner a singolo job con ambito di repository su DigitalOcean, AWS, Google Cloud e Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Un esploratore statico per i dati sul solare distribuito della California, con metodologia e limiti espliciti di copertura e modellazione | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Workflow di acquisizione su macOS per applicazioni di produttività, basati su AppleScript, Automator e Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Una CLI interattiva in Rust per comporre messaggi Conventional Commit | |
| [Controllo del prezzo di Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Un plugin Nagios/Icinga con soglie di prezzo, controlli opzionali sulla freschezza delle quotazioni e tentativi di richiesta limitati | |

Il README, il codice sorgente e i risultati dei workflow di ciascun progetto ne definiscono l'ambito attuale. Le funzionalità sperimentali e le integrazioni specifiche per piattaforma richiedono una propria validazione; un badge non costituisce una dichiarazione di idoneità alla produzione.

## Altri progetti

- **Monitoraggio di rete:** [Kadupul](https://github.com/kadupulhq/kadupul), un progetto di monitoraggio derivato da Cacti all'interno dell'organizzazione `kadupulhq`.
- **Configurazione dell'infrastruttura:** automazione per [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) e [firewall dell'host](https://github.com/somethingwithproof/ansible-collection-firewall), con limiti specifici dell'implementazione documentati in ciascun repository.
- **Integrazione macOS:** [Server MCP](https://github.com/somethingwithproof/mcp-servers), il repository consolidato per le integrazioni applicative.
- **Strumenti CI:** [Foundry](https://github.com/somethingwithproof/foundry), un command runner basato su profili con pianificazione delle dipendenze e log di esecuzione.

Mi occupo anche di workflow per prove genealogiche e di ricerca sui dati di mercato. Questi interessi non implicano conclusioni di ricerca certificate, performance di trading verificate né la disponibilità pubblica di ogni repository di ricerca.

## Segnalazioni di sicurezza

Segui il file `SECURITY.md` del repository interessato e il relativo canale privato di segnalazione configurato. Per i progetti upstream, utilizza la procedura di divulgazione del progetto upstream. Evita di aprire issue pubbliche contenenti dettagli di vulnerabilità non divulgate o credenziali.
