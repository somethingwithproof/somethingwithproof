## ሌሎች ሥራዎች

- **የአውታረ መረብ ክትትል፦** በ`kadupulhq` ድርጅት ሥር የሚገኝ ከCacti የተገኘ የክትትል ፕሮጀክት የሆነው [Kadupul](https://github.com/kadupulhq/kadupul)።

- **የCI መሣሪያዎች፦** የጥገኝነት ዕቅድ እና የአፈጻጸም ምዝግብ ማስታወሻዎች ያሉት በመገለጫ ላይ የተመሠረተ የትዕዛዝ አስኪያጅ የሆነው [Foundry](https://github.com/somethingwithproof/foundry)።

በተጨማሪም በዘር ሐረግ ማስረጃ የሥራ ፍሰቶች እና በገበያ ውሂብ ምርምር ላይ እሠራለሁ። እነዚህ ፍላጎቶች የተረጋገጡ የምርምር መደምደሚያዎችን፣ የተረጋገጠ የንግድ አፈጻጸምን ወይም የእያንዳንዱን የምርምር ማከማቻ ይፋዊ ተደራሽነት አያመለክቱም።
