# Thomas Vincent

Nkora ibikoresho byo gucunga ibikorwaremezo, kwikoresha imirimo ya macOS, no koroshya igenzura ry'imyitwarire ya sisitemu. Imirimo yanjye ikubiyemo Go, Python, Rust, PHP, TypeScript, n'igenamiterere ry'ibikorwaremezo.

## Imishinga yatoranyijwe

| Umushinga | Icyo utanga |
| --- | --- |
| [Ibikorwaremezo bya GitHub runner](https://github.com/somethingwithproof/github-runners-infra) | Umugenzuzi wa Go wa runner zikora umurimo umwe zigenewe ububiko bumwe kuri DigitalOcean, AWS, Google Cloud, na Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Igikoresho gidahinduka cyo gusuzuma amakuru y'imirasire y'izuba ikwirakwijwe muri California, gifite uburyo bw'ubushakashatsi n'imbibi zisobanutse z'aho kigera n'icyitegererezo | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Urukurikirane rw'ibikorwa byo gufata amakuru kuri macOS ku maporogaramu yongera umusaruro, ukoresheje AppleScript, Automator, na Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | CLI ya Rust ikorana n'uyikoresha igenewe gukora ubutumwa bwa Conventional Commit | |
| [Igenzura ry'igiciro cya Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Umugereka wa Nagios/Icinga ufite imipaka y'ibiciro, igenzura rihitamo ko igiciro ari gishya, n'inshuro zifite imipaka zo kongera gusaba | |

README ya buri mushinga, inkomoko yayo, n'ibisubizo by'urukurikirane rw'ibikorwa bigaragaza aho ugeza ubu. Ibiranga biri mu igerageza n'ihuza ryihariye ku mbuga bikeneye igenzura ryabyo ubwabyo; ikirango nticyemeza ko biteguye gukoreshwa mu mikorere nyayo.

## Indi mirimo

- **Gukurikirana umuyoboro:** [Kadupul](https://github.com/kadupulhq/kadupul), umushinga wo gukurikirana imikorere ukomoka kuri Cacti ubarizwa mu kigo cya `kadupulhq`.
- **Igenamiterere ry'ibikorwaremezo:** Kwikoresha kwa [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), na [firewall y'imashini](https://github.com/somethingwithproof/ansible-collection-firewall), hamwe n'imbibi zihariye ku ishyirwa mu bikorwa zanditswe muri buri bubiko.
- **Ihuza rya macOS:** [Seriveri za MCP](https://github.com/somethingwithproof/mcp-servers), ububiko buhurije hamwe ihuza ry'amaporogaramu.
- **Ibikoresho bya CI:** [Foundry](https://github.com/somethingwithproof/foundry), igikoresho gikoresha amategeko gishingiye ku myirondoro gifite itegura ry'ibikenerwa n'inyandiko z'ishyirwa mu bikorwa.

Nkora kandi ku rukurikirane rw'ibikorwa by'ibimenyetso by'ibisekuru n'ubushakashatsi ku makuru y'isoko. Ibyo nkunda gukoraho ntibisobanura ko hari imyanzuro y'ubushakashatsi yemejwe, imikorere y'ubucuruzi yagenzuwe, cyangwa ko buri bubiko bw'ubushakashatsi buboneka ku mugaragaro.

## Raporo z'umutekano

Kurikiza `SECURITY.md` y'ububiko bireba n'inzira yayo yihariye yo gutanga raporo mu ibanga. Ku mishinga y'isoko y'ibanze, koresha uburyo bwayo bwo gutangaza intege nke. Irinde ibibazo bitangazwa ku mugaragaro birimo amakuru arambuye y'intege nke zitaratangazwa cyangwa amakuru yo kwinjira.
