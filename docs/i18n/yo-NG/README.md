# Thomas Vincent

Mo ń kọ àwọn irinṣẹ́ fún ṣíṣiṣẹ́ àwọn ètò-àmúyẹ, ṣíṣe àwọn ìṣàn-iṣẹ́ macOS ní aládàáṣe, àti mímú kí ìwà ètò rọrùn sí i láti ṣàyẹ̀wò. Iṣẹ́ mi tàn ká Go, Python, Rust, PHP, TypeScript, àti ìṣètò ètò-àmúyẹ.

## Àwọn iṣẹ́ àkànṣe tí a yàn

| Iṣẹ́ àkànṣe | Ohun tí ó pèsè |
| --- | --- |
| [Ètò-àmúyẹ olùṣiṣẹ́ GitHub](https://github.com/somethingwithproof/github-runners-infra) | Olùṣàkóso Go fún àwọn olùṣiṣẹ́ iṣẹ́-kanṣoṣo tí ó dá lórí ibi-ìpamọ́ káàkiri DigitalOcean, AWS, Google Cloud, àti Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Olùṣàwárí aláìyípadà fún dátà oòrùn-pípín ti California, pẹ̀lú ọ̀nà ìṣiṣẹ́ àti àwọn ààlà ìbòmọ́lẹ̀/àwòkọ́ṣe tí a sọ kedere | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Àwọn ìṣàn-iṣẹ́ ìgbàsílẹ̀ macOS fún àwọn ohun-èlò ìmúṣẹ-iṣẹ́, nípa lílo AppleScript, Automator, àti Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | CLI Rust alábàáṣepọ̀ fún kíkọ àwọn ìfìránṣẹ́ Conventional Commit | |

README, orísun, àti àwọn èsì ìṣàn-iṣẹ́ iṣẹ́ àkànṣe kọ̀ọ̀kan ni ó ń ṣàlàyé ìwọ̀n iṣẹ́ rẹ̀ lọ́wọ́lọ́wọ́. Àwọn ẹ̀yà-iṣẹ́ àdánwò àti àwọn ìsopọ̀ pàtó fún pẹpẹ nílò ìjẹ́rìísí tiwọn fúnra wọn; àmì-ìyìn kì í ṣe ẹ̀tọ́ ìmúrasílẹ̀ fún ìṣẹ̀dá gidi.

## Àwọn iṣẹ́ mìíràn

- **Àbójútó nẹ́tíwọ́ọ̀kì:** [Kadupul](https://github.com/kadupulhq/kadupul), iṣẹ́ àkànṣe àbójútó tí ó ti inú Cacti jáde lábẹ́ àjọ `kadupulhq`.
- **Ìṣètò ètò-àmúyẹ:** Ìṣiṣẹ́ aládàáṣe [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), àti [ògiri-iná ẹ̀rọ olùgbàlejò](https://github.com/somethingwithproof/ansible-collection-firewall), pẹ̀lú àwọn ààlà pàtó fún ìmúṣẹ tí a kọ sílẹ̀ nínú ibi-ìpamọ́ kọ̀ọ̀kan.
- **Ìsopọ̀ macOS:** [Àwọn ẹ̀rọ-ìpèsè MCP](https://github.com/somethingwithproof/mcp-servers), ibi-ìpamọ́ àpapọ̀ fún àwọn ìsopọ̀ ohun-èlò.
- **Àwọn irinṣẹ́ CI:** [Foundry](https://github.com/somethingwithproof/foundry), olùṣiṣẹ́ àṣẹ tí ó dá lórí profáìlì pẹ̀lú ìṣètò ìgbẹ́kẹ̀lé àti àwọn àkọsílẹ̀ ìṣiṣẹ́.

Mo tún ń ṣiṣẹ́ lórí àwọn ìṣàn-iṣẹ́ ẹ̀rí ìran-ìdílé àti ìwádìí dátà ọjà. Àwọn ìfẹ́-ọkàn wọ̀nyẹn kò túmọ̀ sí àwọn ìparí ìwádìí tí a fọwọ́sí, iṣẹ́ ìṣòwò tí a jẹ́rìísí, tàbí wíwà gbogbo ibi-ìpamọ́ ìwádìí fún gbogbo ènìyàn.

## Àwọn ìròyìn ààbò

Tẹ̀lé `SECURITY.md` ti ibi-ìpamọ́ tí ọ̀rọ̀ náà kàn àti ikànnì ìròyìn àṣírí rẹ̀ tí a ṣètò. Fún àwọn iṣẹ́ àkànṣe orísun-òkè, lo ìlànà ìfihàn ti iṣẹ́ àkànṣe orísun-òkè náà. Yẹra fún àwọn ọ̀rọ̀ gbangba tí ó ní àlàyé àìlera ààbò tí a kò tíì ṣípayá tàbí àwọn ẹ̀rí ìwọlé nínú.
