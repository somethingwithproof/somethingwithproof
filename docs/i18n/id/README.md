# Thomas Vincent

Saya membangun alat untuk mengoperasikan infrastruktur, mengotomatiskan alur kerja macOS, dan mempermudah pemeriksaan perilaku sistem. Pekerjaan saya mencakup Go, Python, Rust, PHP, TypeScript, dan konfigurasi infrastruktur.

## Proyek pilihan

| Proyek | Yang disediakan |
| --- | --- |
| [Infrastruktur runner GitHub](https://github.com/somethingwithproof/github-runners-infra) | Controller Go untuk runner single-job berskala repositori di DigitalOcean, AWS, Google Cloud, dan Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Penjelajah statis untuk data surya terdistribusi California, lengkap dengan metodologi dan batasan cakupan/pemodelan yang eksplisit | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Alur kerja penangkapan tugas macOS untuk aplikasi produktivitas menggunakan AppleScript, Automator, dan Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | CLI Rust interaktif untuk menyusun pesan Conventional Commit | |
| [Pemeriksaan harga Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Plugin Nagios/Icinga dengan ambang batas harga, pemeriksaan kesegaran kutipan opsional, dan percobaan ulang permintaan yang dibatasi | |

README, kode sumber, dan hasil alur kerja setiap proyek menentukan cakupan saat ini. Fitur eksperimental dan integrasi khusus platform memerlukan validasi tersendiri; sebuah lencana bukan klaim kesiapan produksi.

## Pekerjaan lainnya

- **Pemantauan jaringan:** [Kadupul](https://github.com/kadupulhq/kadupul), proyek pemantauan turunan Cacti di bawah organisasi `kadupulhq`.
- **Konfigurasi infrastruktur:** Otomatisasi [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), dan [firewall host](https://github.com/somethingwithproof/ansible-collection-firewall), dengan batasan khusus implementasi yang didokumentasikan di setiap repositori.
- **Integrasi macOS:** [Server MCP](https://github.com/somethingwithproof/mcp-servers), repositori terpadu untuk integrasi aplikasi.
- **Alat CI:** [Foundry](https://github.com/somethingwithproof/foundry), pelaksana perintah berbasis profil dengan perencanaan dependensi dan log eksekusi.

Saya juga mengerjakan alur kerja bukti genealogi dan riset data pasar. Minat tersebut tidak menyiratkan kesimpulan riset tersertifikasi, kinerja perdagangan terverifikasi, atau ketersediaan publik dari setiap repositori riset.

## Laporan keamanan

Ikuti `SECURITY.md` pada repositori terdampak beserta saluran pelaporan privat yang dikonfigurasi. Untuk proyek hulu, gunakan proses pengungkapan proyek hulu tersebut. Hindari membuat isu publik yang memuat rincian kerentanan yang belum diungkapkan atau kredensial.
