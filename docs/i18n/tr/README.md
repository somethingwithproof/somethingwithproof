# Thomas Vincent

Altyapı işletimi, macOS iş akışlarının otomatikleştirilmesi ve sistem davranışlarının daha kolay incelenmesi için araçlar geliştiriyorum. Çalışmalarım Go, Python, Rust, PHP, TypeScript ve altyapı yapılandırmasını kapsıyor.

## Seçili projeler

| Proje | Ne sağlar |
| --- | --- |
| [GitHub runner altyapısı](https://github.com/somethingwithproof/github-runners-infra) | DigitalOcean, AWS, Google Cloud ve Azure genelinde depo kapsamlı, tek görevli çalıştırıcılar için bir Go denetleyicisi | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Metodoloji ve açık kapsam/modelleme sınırlarıyla Kaliforniya dağıtık güneş enerjisi verileri için statik bir gezgin | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | AppleScript, Automator ve Alfred kullanan üretkenlik uygulamaları için macOS veri yakalama iş akışları | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Conventional Commit mesajları oluşturmak için etkileşimli bir Rust CLI aracı | |
| [Bitcoin fiyat kontrolü](https://github.com/somethingwithproof/check_bitcoin_price) | Fiyat eşikleri, isteğe bağlı fiyat güncelliği kontrolleri ve sınırlı istek yeniden denemeleri içeren bir Nagios/Icinga eklentisi | |

Her projenin README dosyası, kaynak kodu ve iş akışı sonuçları mevcut kapsamını belirler. Deneysel özellikler ve platforma özgü entegrasyonlar kendi doğrulamalarını gerektirir; bir rozet, üretime hazır olma iddiası değildir.

## Diğer çalışmalar

- **Ağ izleme:** `kadupulhq` organizasyonu altında Cacti tabanlı bir izleme projesi olan [Kadupul](https://github.com/kadupulhq/kadupul).
- **Altyapı yapılandırması:** Her depoda uygulamaya özgü sınırları belgelenmiş [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) ve [ana bilgisayar güvenlik duvarı](https://github.com/somethingwithproof/ansible-collection-firewall) otomasyonu.
- **macOS entegrasyonu:** Uygulama entegrasyonları için birleştirilmiş depo olan [MCP sunucuları](https://github.com/somethingwithproof/mcp-servers).
- **CI araçları:** Bağımlılık planlaması ve yürütme günlükleri içeren profil tabanlı komut çalıştırıcısı [Foundry](https://github.com/somethingwithproof/foundry).

Ayrıca soyağacı kanıt iş akışları ve piyasa verisi araştırmaları üzerine çalışıyorum. Bu ilgi alanları sertifikalı araştırma sonuçları, doğrulanmış alım-satım performansı veya her araştırma deposunun herkese açık olması anlamına gelmez.

## Güvenlik bildirimleri

Etkilenen deponun `SECURITY.md` dosyasını ve yapılandırılmış özel bildirim kanalını izleyin. Yukarı akış projeleri için ilgili projenin bildirim sürecini kullanın. Açıklanmamış güvenlik açığı ayrıntılarını veya kimlik bilgilerini içeren herkese açık sorun kayıtlarından kaçının.
