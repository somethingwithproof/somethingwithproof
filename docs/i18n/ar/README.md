# Thomas Vincent

أطوّر أدوات لتشغيل البنية التحتية، وأتمتة سير عمل macOS، وتسهيل فحص سلوك الأنظمة. يمتد عملي عبر Go وPython وRust وPHP وTypeScript وتهيئة البنية التحتية.

## مشاريع مختارة

| المشروع | ما يقدمه |
| --- | --- |
| [بنية مشغّلات GitHub](https://github.com/somethingwithproof/github-runners-infra) | وحدة تحكم بلغة Go لمشغّلات المهام الفردية المخصّصة لكل مستودع عبر DigitalOcean وAWS وGoogle Cloud وAzure |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | مستكشف ثابت لبيانات الطاقة الشمسية الموزّعة في كاليفورنيا، يتضمن المنهجية وحدود التغطية والنمذجة الصريحة |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | مسارات عمل للالتقاط السريع على macOS لتطبيقات الإنتاجية باستخدام AppleScript وAutomator وAlfred |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | أداة سطر أوامر تفاعلية بلغة Rust لإنشاء رسائل الإيداع وفق معيار Conventional Commits |
| [فحص سعر Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | إضافة لنظامي Nagios وIcinga تتضمن عتبات للأسعار، وفحوصات اختيارية لحداثة الأسعار، ومحاولات إعادة محدودة للطلبات |

يحدّد ملف README والشفرة المصدرية ونتائج سير العمل لكل مشروع نطاقه الحالي. وتحتاج الميزات التجريبية والتكاملات الخاصة بالمنصات إلى تحققها المستقل؛ فوجود شارة لا يُعدّ ادعاءً بالجاهزية للإنتاج.

## أعمال أخرى

- **مراقبة الشبكات:** [Kadupul](https://github.com/kadupulhq/kadupul)، وهو مشروع مراقبة مشتق من Cacti تحت مؤسسة `kadupulhq`.
- **تهيئة البنية التحتية:** أتمتة [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb) و[WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) و[جدار حماية المضيف](https://github.com/somethingwithproof/ansible-collection-firewall)، مع توثيق الحدود الخاصة بكل تنفيذ في مستودعه.
- **تكامل macOS:** [خوادم MCP](https://github.com/somethingwithproof/mcp-servers)، المستودع الموحّد لتكاملات التطبيقات.
- **أدوات التكامل المستمر (CI):** [Foundry](https://github.com/somethingwithproof/foundry)، مشغّل أوامر قائم على ملفات التعريف (profiles) مع تخطيط التبعيات وسجلات التنفيذ.

أعمل أيضاً على سير عمل أدلة علم الأنساب وأبحاث بيانات السوق. ولا تعني هذه الاهتمامات استنتاجات بحثية معتمدة، أو أداء تداول متحقَّقاً منه، أو إتاحة كل مستودع بحثي للعامة.

## البلاغات الأمنية

اتبع ملف `SECURITY.md` الخاص بالمستودع المتأثر وقناة الإبلاغ الخاصة المُهيّأة فيه. أما بالنسبة للمشاريع الأصلية (upstream)، فاستخدم إجراءات الإفصاح الخاصة بها. وتجنّب فتح قضايا عامة تحتوي على تفاصيل ثغرات غير مفصح عنها أو بيانات اعتماد.
