# Thomas Vincent

인프라 운영, macOS 워크플로 자동화, 그리고 시스템 동작을 더 쉽게 점검할 수 있게 해주는 도구를 개발합니다. Go, Python, Rust, PHP, TypeScript 및 인프라 구성 전반에 걸쳐 작업하고 있습니다.

## 주요 프로젝트

| 프로젝트 | 제공 기능 |
| --- | --- |
| [GitHub 러너 인프라](https://github.com/somethingwithproof/github-runners-infra) | DigitalOcean, AWS, Google Cloud, Azure 전반에서 저장소 범위의 단일 작업 러너를 관리하는 Go 컨트롤러 | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | 방법론과 명시적인 범위/모델링 한계를 함께 제공하는 캘리포니아 분산형 태양광 데이터 정적 탐색기 | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | AppleScript, Automator, Alfred를 사용하는 생산성 앱용 macOS 캡처 워크플로 | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Conventional Commit 메시지를 작성하기 위한 대화형 Rust CLI | |
| [비트코인 가격 확인](https://github.com/somethingwithproof/check_bitcoin_price) | 가격 임계값, 선택적 시세 최신성 검사, 제한된 요청 재시도를 지원하는 Nagios/Icinga 플러그인 | |

각 프로젝트의 현재 범위는 해당 프로젝트의 README, 소스 코드, 워크플로 결과에 의해 정의됩니다. 실험적 기능과 플랫폼별 연동은 별도의 검증이 필요하며, 배지가 프로덕션 준비 완료를 의미하지는 않습니다.

## 기타 작업

- **네트워크 모니터링:** `kadupulhq` 조직에서 진행하는 Cacti 기반 모니터링 프로젝트인 [Kadupul](https://github.com/kadupulhq/kadupul).
- **인프라 구성:** [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), [호스트 방화벽](https://github.com/somethingwithproof/ansible-collection-firewall) 자동화 프로젝트로, 구현별 한계는 각 저장소에 문서화되어 있습니다.
- **macOS 연동:** 애플리케이션 연동을 통합 관리하는 저장소인 [MCP 서버](https://github.com/somethingwithproof/mcp-servers).
- **CI 도구:** 의존성 계획 및 실행 로그 기능을 갖춘 프로필 기반 명령 실행기 [Foundry](https://github.com/somethingwithproof/foundry).

계보학적 증거 워크플로와 시장 데이터 연구도 수행하고 있습니다. 이러한 관심 분야가 공인된 연구 결론, 검증된 거래 성과 또는 모든 연구 저장소의 공개 여부를 의미하지는 않습니다.

## 보안 제보

영향을 받는 저장소의 `SECURITY.md`와 해당 저장소에 구성된 비공개 제보 채널을 따라 주세요. 업스트림 프로젝트의 경우 업스트림 프로젝트의 공개 절차를 사용하세요. 공개되지 않은 취약점 세부 정보나 자격 증명이 포함된 공개 이슈는 작성하지 마세요.
