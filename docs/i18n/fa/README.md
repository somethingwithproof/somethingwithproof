# Thomas Vincent

من ابزارهایی برای راه‌اندازی و راهبری زیرساخت، خودکارسازی گردش‌کارهای macOS و آسان‌تر کردن بررسی رفتار سیستم‌ها می‌سازم. کار من شامل Go، Python، Rust، PHP، TypeScript و پیکربندی زیرساخت است.

## پروژه‌های برگزیده

| پروژه | آنچه ارائه می‌دهد |
| --- | --- |
| [زیرساخت runnerهای GitHub](https://github.com/somethingwithproof/github-runners-infra) | یک کنترلر Go برای runnerهای تک‌وظیفه‌ای در سطح مخزن روی DigitalOcean، AWS، Google Cloud و Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | یک کاوشگر ایستا برای داده‌های خورشیدی توزیع‌شده کالیفرنیا، به همراه روش‌شناسی و محدودیت‌های صریح پوشش و مدل‌سازی | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | گردش‌کارهای ثبت سریع در macOS برای برنامه‌های بهره‌وری با استفاده از AppleScript، Automator و Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | یک ابزار خط فرمان تعاملی به زبان Rust برای ساخت پیام‌های Conventional Commit | |
| [بررسی قیمت بیت‌کوین](https://github.com/somethingwithproof/check_bitcoin_price) | یک افزونه Nagios/Icinga با آستانه‌های قیمت، بررسی اختیاری تازگی نرخ و تلاش مجدد محدود برای درخواست‌ها | |

README، کد منبع و نتایج گردش‌کار هر پروژه محدوده فعلی آن را تعریف می‌کنند. قابلیت‌های آزمایشی و یکپارچه‌سازی‌های وابسته به پلتفرم نیازمند اعتبارسنجی مستقل هستند؛ وجود یک نشان (badge) به معنای ادعای آمادگی برای محیط عملیاتی نیست.

## سایر فعالیت‌ها

- **پایش شبکه:** [Kadupul](https://github.com/kadupulhq/kadupul)، یک پروژه پایش برگرفته از Cacti زیر نظر سازمان `kadupulhq`.
- **پیکربندی زیرساخت:** خودکارسازی [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb)، [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) و [فایروال میزبان](https://github.com/somethingwithproof/ansible-collection-firewall)، به همراه محدودیت‌های خاص پیاده‌سازی که در هر مخزن مستند شده‌اند.
- **یکپارچه‌سازی macOS:** [سرورهای MCP](https://github.com/somethingwithproof/mcp-servers)، مخزن یکپارچه برای اتصال به برنامه‌ها.
- **ابزارهای CI:** [Foundry](https://github.com/somethingwithproof/foundry)، یک اجراکننده دستورات مبتنی بر پروفایل با برنامه‌ریزی وابستگی‌ها و گزارش‌های اجرا.

من همچنین روی گردش‌کارهای شواهد تبارشناسی و پژوهش داده‌های بازار کار می‌کنم. این حوزه‌های علاقه‌مندی به معنای نتایج پژوهشی تاییدشده، عملکرد معاملاتی راستی‌آزمایی‌شده یا دسترسی عمومی به همه مخازن پژوهشی نیستند.

## گزارش‌های امنیتی

از فایل `SECURITY.md` مخزن متأثر و کانال گزارش‌دهی خصوصی پیکربندی‌شده آن پیروی کنید. برای پروژه‌های بالادستی، از فرایند افشای همان پروژه بالادستی استفاده کنید. از ثبت گزارش‌های عمومی حاوی جزئیات آسیب‌پذیری‌های افشانشده یا اعتبارنامه‌ها خودداری کنید.
