# Thomas Vincent

Я створюю інструменти для експлуатації інфраструктури, автоматизації робочих процесів у macOS та спрощення аналізу поведінки систем. Моя робота охоплює Go, Python, Rust, PHP, TypeScript і конфігурацію інфраструктури.

## Вибрані проєкти

| Проєкт | Що забезпечує |
| --- | --- |
| [Інфраструктура раннерів GitHub](https://github.com/somethingwithproof/github-runners-infra) | Контролер на Go для одноразових раннерів рівня репозиторію в DigitalOcean, AWS, Google Cloud і Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Статичний оглядач даних про розподілену сонячну енергетику Каліфорнії з описом методології та явними обмеженнями охоплення й моделювання | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Робочі процеси фіксації завдань у macOS для застосунків підвищення продуктивності з використанням AppleScript, Automator і Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Інтерактивний CLI на Rust для формування повідомлень комітів у форматі Conventional Commit | |
| [Перевірка ціни Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Плагін для Nagios/Icinga з пороговими значеннями ціни, необов'язковою перевіркою актуальності котирувань та обмеженою кількістю повторних запитів | |

Файл README, вихідний код і результати робочих процесів кожного проєкту визначають його поточні межі. Експериментальні функції та платформно-залежні інтеграції потребують окремої перевірки; бейдж не є гарантією готовності до промислової експлуатації.

## Інша робота

- **Моніторинг мережі:** [Kadupul](https://github.com/kadupulhq/kadupul) — проєкт моніторингу на основі Cacti в межах організації `kadupulhq`.
- **Конфігурація інфраструктури:** автоматизація [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) і [брандмауера хоста](https://github.com/somethingwithproof/ansible-collection-firewall) з обмеженнями конкретних реалізацій, задокументованими в кожному репозиторії.
- **Інтеграція з macOS:** [MCP-сервери](https://github.com/somethingwithproof/mcp-servers) — об'єднаний репозиторій для інтеграцій із застосунками.
- **Інструменти CI:** [Foundry](https://github.com/somethingwithproof/foundry) — засіб запуску команд на основі профілів із плануванням залежностей і журналами виконання.

Я також працюю над робочими процесами опрацювання генеалогічних доказів та дослідженням ринкових даних. Ці напрями не передбачають сертифікованих дослідницьких висновків, підтверджених торгових результатів або публічної доступності кожного дослідницького репозиторію.

## Звіти про безпеку

Дотримуйтеся файлу `SECURITY.md` відповідного репозиторію та налаштованого в ньому приватного каналу повідомлень. Для апстрім-проєктів використовуйте процес розкриття вразливостей відповідного апстрім-проєкту. Уникайте публічних звернень із нерозкритими деталями вразливостей або обліковими даними.
