# Thomas Vincent

मैं इन्फ़्रास्ट्रक्चर संचालित करने, macOS वर्कफ़्लो को स्वचालित करने और सिस्टम के व्यवहार को आसानी से जाँचने योग्य बनाने के लिए टूल बनाता हूँ। मेरा कार्य Go, Python, Rust, PHP, TypeScript और इन्फ़्रास्ट्रक्चर कॉन्फ़िगरेशन तक विस्तृत है।

## चयनित प्रोजेक्ट

| प्रोजेक्ट | यह क्या प्रदान करता है |
| --- | --- |
| [GitHub रनर इन्फ़्रास्ट्रक्चर](https://github.com/somethingwithproof/github-runners-infra) | DigitalOcean, AWS, Google Cloud और Azure पर रिपॉजिटरी-स्कोप्ड, सिंगल-जॉब रनर के लिए एक Go कंट्रोलर | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | कैलिफ़ोर्निया के वितरित-सौर डेटा के लिए एक स्टैटिक एक्सप्लोरर, जिसमें कार्यप्रणाली और स्पष्ट कवरेज/मॉडलिंग सीमाएँ शामिल हैं | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | AppleScript, Automator और Alfred का उपयोग करके उत्पादकता अनुप्रयोगों के लिए macOS कैप्चर वर्कफ़्लो | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Conventional Commit संदेश बनाने के लिए एक इंटरैक्टिव Rust CLI | |
| [बिटकॉइन मूल्य जाँच](https://github.com/somethingwithproof/check_bitcoin_price) | मूल्य सीमा, वैकल्पिक कोट-फ़्रेशनेस जाँच और सीमित अनुरोध पुनर्प्रयासों वाला एक Nagios/Icinga प्लगइन | |

प्रत्येक प्रोजेक्ट का README, स्रोत और वर्कफ़्लो परिणाम उसका वर्तमान दायरा परिभाषित करते हैं। प्रायोगिक फ़ीचर और प्लेटफ़ॉर्म-विशिष्ट एकीकरण के लिए स्वयं के सत्यापन की आवश्यकता होती है; कोई बैज प्रोडक्शन-तैयारी का दावा नहीं है।

## अन्य कार्य

- **नेटवर्क मॉनिटरिंग:** [Kadupul](https://github.com/kadupulhq/kadupul), `kadupulhq` संगठन के अंतर्गत Cacti-आधारित एक मॉनिटरिंग प्रोजेक्ट।
- **इन्फ़्रास्ट्रक्चर कॉन्फ़िगरेशन:** [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), और [होस्ट फ़ायरवॉल](https://github.com/somethingwithproof/ansible-collection-firewall) स्वचालन, प्रत्येक रिपॉजिटरी में प्रलेखित कार्यान्वयन-विशिष्ट सीमाओं के साथ।
- **macOS एकीकरण:** [MCP सर्वर](https://github.com/somethingwithproof/mcp-servers), अनुप्रयोग एकीकरण के लिए समेकित रिपॉजिटरी।
- **CI टूलिंग:** [Foundry](https://github.com/somethingwithproof/foundry), निर्भरता योजना और निष्पादन लॉग के साथ एक प्रोफ़ाइल-आधारित कमांड रनर।

मैं वंशावली साक्ष्य वर्कफ़्लो और बाज़ार-डेटा अनुसंधान पर भी कार्य करता हूँ। इन रुचियों का अर्थ प्रमाणित अनुसंधान निष्कर्ष, सत्यापित ट्रेडिंग प्रदर्शन या प्रत्येक अनुसंधान रिपॉजिटरी की सार्वजनिक उपलब्धता नहीं है।

## सुरक्षा रिपोर्ट

प्रभावित रिपॉजिटरी की `SECURITY.md` फ़ाइल और उसके कॉन्फ़िगर किए गए निजी रिपोर्टिंग चैनल का पालन करें। अपस्ट्रीम प्रोजेक्ट के लिए अपस्ट्रीम प्रोजेक्ट की प्रकटीकरण प्रक्रिया का उपयोग करें। अघोषित सुरक्षा कमज़ोरियों के विवरण या क्रेडेंशियल वाले सार्वजनिक इश्यू बनाने से बचें।
