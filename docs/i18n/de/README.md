# Thomas Vincent

Ich entwickle Werkzeuge für den Betrieb von Infrastruktur, die Automatisierung von macOS-Workflows und die bessere Nachvollziehbarkeit von Systemverhalten. Meine Arbeit umfasst Go, Python, Rust, PHP, TypeScript und Infrastrukturkonfiguration.

## Ausgewählte Projekte

| Projekt | Funktionsumfang |
| --- | --- |
| [GitHub-Runner-Infrastruktur](https://github.com/somethingwithproof/github-runners-infra) | Ein Go-Controller für Repository-gebundene Single-Job-Runner auf DigitalOcean, AWS, Google Cloud und Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Ein statischer Explorer für Daten zur dezentralen Solarenergie in Kalifornien mit Methodik sowie expliziten Abdeckungs- und Modellierungsgrenzen | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | macOS-Erfassungsworkflows für Produktivitätsanwendungen mit AppleScript, Automator und Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Eine interaktive Rust-CLI zum Erstellen von Conventional-Commit-Nachrichten | |
| [Bitcoin-Preisprüfung](https://github.com/somethingwithproof/check_bitcoin_price) | Ein Nagios-/Icinga-Plugin mit Preisschwellenwerten, optionalen Prüfungen auf Kursaktualität und begrenzten Wiederholungsversuchen bei Anfragen | |

Das README, der Quellcode und die Workflow-Ergebnisse jedes Projekts definieren dessen aktuellen Umfang. Experimentelle Funktionen und plattformspezifische Integrationen erfordern eine eigene Validierung; ein Badge ist keine Zusicherung der Produktionsreife.

## Weitere Arbeiten

- **Netzwerküberwachung:** [Kadupul](https://github.com/kadupulhq/kadupul), ein von Cacti abgeleitetes Monitoring-Projekt unter der Organisation `kadupulhq`.
- **Infrastrukturkonfiguration:** Automatisierung für [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) und [Host-Firewalls](https://github.com/somethingwithproof/ansible-collection-firewall) mit jeweils im Repository dokumentierten implementierungsspezifischen Grenzen.
- **macOS-Integration:** [MCP-Server](https://github.com/somethingwithproof/mcp-servers), das konsolidierte Repository für Anwendungsintegrationen.
- **CI-Werkzeuge:** [Foundry](https://github.com/somethingwithproof/foundry), ein profilbasierter Command-Runner mit Abhängigkeitsplanung und Ausführungsprotokollen.

Darüber hinaus arbeite ich an Workflows für genealogische Belege und an der Marktdatenforschung. Diese Interessen implizieren weder zertifizierte Forschungsergebnisse noch verifizierte Handelsperformance oder die öffentliche Verfügbarkeit jedes Forschungs-Repositorys.

## Sicherheitsmeldungen

Folgen Sie der `SECURITY.md` des betroffenen Repositorys und dem dort konfigurierten privaten Meldekanal. Nutzen Sie bei Upstream-Projekten das jeweilige Offenlegungsverfahren des Upstream-Projekts. Vermeiden Sie öffentliche Issues mit unveröffentlichten Schwachstellendetails oder Zugangsdaten.
