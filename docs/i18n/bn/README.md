# Thomas Vincent

আমি অবকাঠামো পরিচালনা, macOS ওয়ার্কফ্লো স্বয়ংক্রিয়করণ এবং সিস্টেমের আচরণ সহজে পর্যবেক্ষণযোগ্য করার জন্য টুল তৈরি করি। আমার কাজের ক্ষেত্র Go, Python, Rust, PHP, TypeScript এবং অবকাঠামো কনফিগারেশন জুড়ে বিস্তৃত।

## নির্বাচিত প্রকল্পসমূহ

| প্রকল্প | যা প্রদান করে |
| --- | --- |

| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | ক্যালিফোর্নিয়ার ডিস্ট্রিবিউটেড-সোলার ডেটার জন্য একটি স্ট্যাটিক এক্সপ্লোরার, যেখানে কার্যপদ্ধতি এবং কভারেজ/মডেলিংয়ের সুস্পষ্ট সীমাবদ্ধতা উল্লেখ রয়েছে | |

| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Conventional Commit বার্তা তৈরির জন্য একটি ইন্টারঅ্যাক্টিভ Rust CLI | |

প্রতিটি প্রকল্পের README, সোর্স এবং ওয়ার্কফ্লো ফলাফল এর বর্তমান পরিধি নির্ধারণ করে। পরীক্ষামূলক ফিচার এবং প্ল্যাটফর্ম-নির্দিষ্ট ইন্টিগ্রেশনগুলোর জন্য নিজস্ব যাচাইকরণ প্রয়োজন; একটি ব্যাজ প্রোডাকশন-প্রস্তুতির দাবি নয়।

## অন্যান্য কাজ

- **নেটওয়ার্ক মনিটরিং:** [Kadupul](https://github.com/kadupulhq/kadupul), `kadupulhq` সংস্থার অধীনে Cacti-ভিত্তিক একটি মনিটরিং প্রকল্প।
- **অবকাঠামো কনফিগারেশন:** [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), এবং [হোস্ট ফায়ারওয়াল](https://github.com/somethingwithproof/ansible-collection-firewall) অটোমেশন, যার বাস্তবায়ন-নির্দিষ্ট সীমাবদ্ধতাগুলো প্রতিটি রিপোজিটরিতে নথিভুক্ত আছে।
- **macOS ইন্টিগ্রেশন:** [MCP সার্ভারসমূহ](https://github.com/somethingwithproof/mcp-servers), অ্যাপ্লিকেশন ইন্টিগ্রেশনগুলোর জন্য সমন্বিত রিপোজিটরি।
- **CI টুলিং:** [Foundry](https://github.com/somethingwithproof/foundry), ডিপেন্ডেন্সি প্ল্যানিং এবং এক্সিকিউশন লগসহ একটি প্রোফাইল-ভিত্তিক কমান্ড রানার।

আমি বংশতালিকাগত প্রমাণ ওয়ার্কফ্লো এবং মার্কেট-ডেটা গবেষণাতেও কাজ করি। এই আগ্রহগুলো সার্টিফায়েড গবেষণার ফলাফল, যাচাইকৃত ট্রেডিং পারফরম্যান্স বা প্রতিটি গবেষণা রিপোজিটরির সর্বজনীন প্রাপ্যতা নির্দেশ করে না।

## নিরাপত্তা প্রতিবেদন

প্রভাবিত রিপোজিটরির `SECURITY.md` এবং এর কনফিগার করা ব্যক্তিগত রিপোর্টিং চ্যানেল অনুসরণ করুন। আপস্ট্রিম প্রকল্পগুলোর জন্য সংশ্লিষ্ট আপস্ট্রিম প্রকল্পের ডিসক্লোজার প্রক্রিয়া ব্যবহার করুন। অপ্রকাশিত দুর্বলতার বিবরণ বা ক্রেডেনশিয়ালসহ পাবলিক ইস্যু খোলা এড়িয়ে চলুন।
