# Thomas Vincent

ببني أدوات لتشغيل البنية التحتية، وأتمتة مسارات الشغل على macOS، وتسهيل فحص سلوك الأنظمة. شغلي بيغطي Go وPython وRust وPHP وTypeScript وإعدادات البنية التحتية.

## مشاريع مختارة

| المشروع | بيقدّم إيه |
| --- | --- |
| [بنية تشغيل GitHub runners](https://github.com/somethingwithproof/github-runners-infra) | أداة تحكم بـ Go لتشغيل runners على مستوى المستودع وبمهمة واحدة عبر DigitalOcean وAWS وGoogle Cloud وAzure |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | مستعرض ثابت (static explorer) لبيانات الطاقة الشمسية الموزّعة في كاليفورنيا، مع المنهجية وحدود التغطية والنمذجة بشكل واضح |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | مسارات التقاط سريعة (capture workflows) لتطبيقات الإنتاجية على macOS باستخدام AppleScript وAutomator وAlfred |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | أداة CLI تفاعلية مكتوبة بـ Rust علشان تبني رسائل Conventional Commit |
| [فحص سعر Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | إضافة (plugin) لـ Nagios وIcinga فيها حدود للأسعار، وفحوصات اختيارية لحداثة السعر، ومحاولات إعادة طلب محدودة |

ملف README والكود المصدري ونتائج سير العمل لكل مشروع هما اللي بيحددوا نطاقه الحالي. الميزات التجريبية والتكاملات الخاصة بمنصات معينة بتحتاج تحقق خاص بيها؛ ووجود شارة (badge) مش معناه ادعاء بالجاهزية للإنتاج.

## شغل تاني

- **مراقبة الشبكات:** [Kadupul](https://github.com/kadupulhq/kadupul)، مشروع مراقبة مشتق من Cacti تحت منظمة `kadupulhq`.
- **إعدادات البنية التحتية:** أتمتة [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb)، و[WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise)، و[الـ firewall للسيرفر](https://github.com/somethingwithproof/ansible-collection-firewall)، مع توثيق القيود الخاصة بكل تنفيذ في المستودع بتاعه.
- **تكامل macOS:** [سيرفرات MCP](https://github.com/somethingwithproof/mcp-servers)، المستودع الموحّد لتكاملات التطبيقات.
- **أدوات الـ CI:** [Foundry](https://github.com/somethingwithproof/foundry)، مشغّل أوامر مبني على الـ profiles مع تخطيط التبعيات وسجلات التنفيذ.

كمان بشتغل على مسارات أدلة الأنساب (genealogical evidence workflows) وأبحاث بيانات السوق. الاهتمامات دي مش معناها استنتاجات بحثية معتمدة، ولا أداء تداول موثّق، ولا إن كل مستودع بحثي متاح للعامة.

## بلاغات الأمان

اتبع ملف `SECURITY.md` في المستودع المتأثر وقناة الإبلاغ الخاصة المضبوطة فيه. بالنسبة للمشاريع الأصلية (upstream)، استخدم إجراءات الإفصاح الخاصة بالمشروع الأصلي. تجنّب فتح issues عامة فيها تفاصيل ثغرات غير مُعلن عنها أو بيانات اعتماد.
