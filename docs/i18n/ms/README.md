# Thomas Vincent

Saya membina alatan untuk mengendalikan infrastruktur, mengautomasikan aliran kerja macOS, dan memudahkan pemeriksaan tingkah laku sistem. Kerja saya merangkumi Go, Python, Rust, PHP, TypeScript, dan konfigurasi infrastruktur.

## Projek terpilih

| Projek | Perkara yang disediakan |
| --- | --- |
| [Infrastruktur pelari GitHub](https://github.com/somethingwithproof/github-runners-infra) | Pengawal Go untuk pelari tugas tunggal berskop repositori merentas DigitalOcean, AWS, Google Cloud, dan Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Penjelajah statik untuk data suria teragih California, lengkap dengan metodologi serta had liputan/pemodelan yang jelas | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Aliran kerja tangkapan macOS untuk aplikasi produktiviti, menggunakan AppleScript, Automator, dan Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | CLI Rust interaktif untuk membina mesej Conventional Commit | |
| [Semakan harga Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Pemalam Nagios/Icinga dengan ambang harga, semakan kesegaran sebut harga pilihan, dan cubaan semula permintaan terhad | |

README, sumber, dan hasil aliran kerja setiap projek mentakrifkan skop semasanya. Ciri percubaan dan penyepaduan khusus platform memerlukan pengesahannya sendiri; lencana bukanlah tuntutan kesediaan pengeluaran.

## Kerja lain

- **Pemantauan rangkaian:** [Kadupul](https://github.com/kadupulhq/kadupul), projek pemantauan terbitan Cacti di bawah organisasi `kadupulhq`.
- **Konfigurasi infrastruktur:** Automasi [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), dan [tembok api hos](https://github.com/somethingwithproof/ansible-collection-firewall), dengan had khusus pelaksanaan yang didokumenkan dalam setiap repositori.
- **Penyepaduan macOS:** [Pelayan MCP](https://github.com/somethingwithproof/mcp-servers), repositori bersepadu untuk penyepaduan aplikasi.
- **Alatan CI:** [Foundry](https://github.com/somethingwithproof/foundry), pelari arahan berasaskan profil dengan perancangan kebergantungan dan log pelaksanaan.

Saya juga mengusahakan aliran kerja bukti salasilah dan penyelidikan data pasaran. Minat tersebut tidak membayangkan kesimpulan penyelidikan yang diperakui, prestasi dagangan yang ditentusahkan, atau ketersediaan awam bagi setiap repositori penyelidikan.

## Laporan keselamatan

Ikuti `SECURITY.md` repositori yang terjejas serta saluran pelaporan peribadi yang dikonfigurasikan. Bagi projek huluan, gunakan proses pendedahan projek huluan tersebut. Elakkan isu awam yang mengandungi butiran kerentanan yang belum didedahkan atau bukti kelayakan.
