# Thomas Vincent

Waxaan dhisaa qalab loogu talagalay hawlgelinta kaabayaasha, otomaatigga socodka shaqada ee macOS, iyo ka dhigista dabeecadda nidaamka mid sahlan in la baaro. Shaqadaydu waxay ka kooban tahay Go, Python, Rust, PHP, TypeScript, iyo habaynta kaabayaasha.

## Mashaariicda la xushay

| Mashruuc | Waxa uu bixiyo |
| --- | --- |
| [Kaabayaasha GitHub runner](https://github.com/somethingwithproof/github-runners-infra) | Koontaroole Go ah oo loogu talagalay runner-rada hal-shaqo ee heer-kaydka ah ee ka shaqeeya DigitalOcean, AWS, Google Cloud, iyo Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Baare deggan (static explorer) oo loogu talagalay xogta tamarta qorraxda ee qaybsan ee California, oo leh hab-raac iyo xaddidaadyo cad oo daboolid iyo qaabayn ah | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Socodyo shaqo oo qabasho macOS ah oo loogu talagalay barnaamijyada wax-soo-saarka, iyadoo la adeegsanayo AppleScript, Automator, iyo Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | CLI Rust ah oo is-dhexgal leh oo loogu talagalay dhisidda farriimaha Conventional Commit | |
| [Hubiyaha qiimaha Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Plugin Nagios/Icinga ah oo leh xadka qiimaha, hubin ikhtiyaari ah oo cusboonaanta qiimaha, iyo isku-dayo codsi oo xaddidan | |

Mashruuc kasta README-giisa, koodhkiisa isha, iyo natiijooyinka socodkiisa shaqada ayaa qeexa baaxaddiisa hadda. Sifooyinka tijaabada ah iyo isku-dhafka u gaarka ah madalaha waxay u baahan yihiin xaqiijintooda u gaarka ah; calaamad (badge) ma aha sheegasho diyaarsanaan wax-soo-saar.

## Shaqooyin kale

- **Kormeerka shabakadda:** [Kadupul](https://github.com/kadupulhq/kadupul), mashruuc kormeer ah oo laga soo minguuriyay Cacti kaas oo hoos yimaada ururka `kadupulhq`.
- **Habaynta kaabayaasha:** otomaatigga [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), iyo [derbiga-dabka martigeliyaha](https://github.com/somethingwithproof/ansible-collection-firewall), iyadoo xaddidaadyada u gaarka ah hirgelinta lagu diiwaangeliyay kayd kasta.
- **Isku-dhafka macOS:** [Server-rada MCP](https://github.com/somethingwithproof/mcp-servers), kaydka midaysan ee isku-dhafka barnaamijyada.
- **Qalabka CI:** [Foundry](https://github.com/somethingwithproof/foundry), socodsiiye amarro oo ku salaysan astaan (profile) kaas oo leh qorshaynta ku-tiirsanaanta iyo diiwaannada fulinta.

Waxaan sidoo kale ka shaqeeyaa socodka shaqada ee caddaymaha abtirsiga iyo cilmi-baarista xogta suuqa. Xiisahaasi ma tusayo natiijooyin cilmi-baaris oo la caddeeyay, waxqabad ganacsi oo la xaqiijiyay, ama helitaanka dadweynaha ee kayd kasta oo cilmi-baaris ah.

## Warbixinnada amniga

Raac `SECURITY.md` ee kaydka ay khusayso iyo kanaalka warbixinta gaarka ah ee u habaysan. Mashaariicda sare (upstream), isticmaal habka shaacinta ee mashruuca sare. Ka fogow arrimaha dadweynaha (public issues) ee ay ku jiraan faahfaahinta baylahda aan la shaacin ama aqoonsiyada.
