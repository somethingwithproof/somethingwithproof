# Thomas Vincent

Desarrollo herramientas para operar infraestructura, automatizar flujos de trabajo en macOS y facilitar la inspección del comportamiento de los sistemas. Mi trabajo abarca Go, Python, Rust, PHP, TypeScript y configuración de infraestructura.

## Proyectos destacados

| Proyecto | Qué ofrece |
| --- | --- |
| [Infraestructura de runners de GitHub](https://github.com/somethingwithproof/github-runners-infra) | Un controlador en Go para runners de un solo trabajo con alcance de repositorio en DigitalOcean, AWS, Google Cloud y Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Un explorador estático de datos de energía solar distribuida en California, con metodología y límites explícitos de cobertura y modelado | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Flujos de trabajo de captura en macOS para aplicaciones de productividad mediante AppleScript, Automator y Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Una CLI interactiva en Rust para construir mensajes de Conventional Commit | |
| [Verificación de precio de Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Un complemento para Nagios/Icinga con umbrales de precio, comprobaciones opcionales de vigencia de cotizaciones y reintentos acotados de solicitudes | |

El README, el código fuente y los resultados de los flujos de trabajo de cada proyecto definen su alcance actual. Las funcionalidades experimentales y las integraciones específicas de plataforma requieren su propia validación; una insignia no implica preparación para producción.

## Otros trabajos

- **Monitorización de red:** [Kadupul](https://github.com/kadupulhq/kadupul), un proyecto de monitorización derivado de Cacti bajo la organización `kadupulhq`.
- **Configuración de infraestructura:** automatización de [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) y [firewall de host](https://github.com/somethingwithproof/ansible-collection-firewall), con límites específicos de implementación documentados en cada repositorio.
- **Integración con macOS:** [servidores MCP](https://github.com/somethingwithproof/mcp-servers), el repositorio consolidado para integraciones con aplicaciones.
- **Herramientas de CI:** [Foundry](https://github.com/somethingwithproof/foundry), un ejecutor de comandos basado en perfiles con planificación de dependencias y registros de ejecución.

También trabajo en flujos de trabajo de evidencia genealógica e investigación de datos de mercado. Estos intereses no implican conclusiones de investigación certificadas, rendimiento bursátil verificado ni la disponibilidad pública de todos los repositorios de investigación.

## Informes de seguridad

Siga el archivo `SECURITY.md` del repositorio afectado y su canal privado de notificación configurado. Para proyectos upstream, utilice el proceso de divulgación del proyecto upstream. Evite abrir incidencias públicas que contengan detalles de vulnerabilidades no divulgadas o credenciales.
