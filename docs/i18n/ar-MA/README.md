# Thomas Vincent

كنصاوب أدوات لتشغيل البنية التحتية، وأتمتة مسارات العمل على macOS، وتسهيل فحص ومراقبة سلوك الأنظمة. الخدمة ديالي كتغطي Go، وPython، وRust، وPHP، وTypeScript، وإعدادات البنية التحتية.

## مشاريع مختارة

| المشروع | شنو كيقدم |
| --- | --- |
| [البنية التحتية لمشغلات GitHub](https://github.com/somethingwithproof/github-runners-infra) | متحكم مكتوب بـ Go لمشغلات (runners) بمهمة وحدة ومحددة على مستوى المستودع عبر DigitalOcean، وAWS، وGoogle Cloud، وAzure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | مستكشف ساكن (static explorer) لبيانات الطاقة الشمسية الموزعة فـ California، مع المنهجية وحدود التغطية والنمذجة موضحة بشكل صريح | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | مسارات عمل لالتقاط المهام على macOS لتطبيقات الإنتاجية، باستعمال AppleScript، وAutomator، وAlfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | أداة سطر أوامر (CLI) تفاعلية مكتوبة بـ Rust باش تصاوب رسائل Conventional Commit | |
| [فحص سعر Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | إضافة Nagios/Icinga مع عتبات السعر، وفحوصات اختيارية لحداثة السعر، وإعادة محاولات محدودة للطلبات | |

ملف README ديال كل مشروع، والكود المصدري ديالو، ونتائج مسارات العمل هما اللي كيحددو النطاق الحالي ديالو. الميزات التجريبية والتكاملات الخاصة بكل منصة كيحتاجو التحقق الخاص بيهم؛ الشارة (badge) ماشي ادعاء بالجاهزية للإنتاج.

## أعمال أخرى

- **مراقبة الشبكات:** [Kadupul](https://github.com/kadupulhq/kadupul)، مشروع مراقبة مشتق من Cacti تحت منظمة `kadupulhq`.
- **إعداد البنية التحتية:** أتمتة [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb)، و[WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise)، و[الجدار الناري للمضيف](https://github.com/somethingwithproof/ansible-collection-firewall)، مع توثيق الحدود الخاصة بكل تنفيذ فالمستودع ديالو.
- **تكامل macOS:** [خوادم MCP](https://github.com/somethingwithproof/mcp-servers)، المستودع الموحد لتكاملات التطبيقات.
- **أدوات CI:** [Foundry](https://github.com/somethingwithproof/foundry)، مشغل أوامر مبني على الملفات التعريفية (profiles) مع تخطيط التبعيات وسجلات التنفيذ.

كنخدم كذلك على مسارات عمل أدلة علم الأنساب وأبحاث بيانات السوق. هاد الاهتمامات ما كتعنيش استنتاجات بحثية معتمدة، ولا أداء تداول متحقق منو، ولا توفر كل مستودع بحثي بشكل عمومي.

## التبليغ عن الثغرات الأمنية

تبع ملف `SECURITY.md` ديال المستودع المعني وقناة التبليغ الخاصة اللي مضبوطة فيه. بالنسبة للمشاريع الأصلية (upstream)، استعمل مسطرة الإفصاح ديال المشروع الأصلي. تجنب فتح قضايا (issues) عمومية فيها تفاصيل ثغرات ما زال ما تفرجش عليها ولا بيانات ولوج سرية.
