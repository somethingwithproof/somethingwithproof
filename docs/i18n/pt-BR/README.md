# Thomas Vincent

Eu crio ferramentas para operar infraestrutura, automatizar fluxos de trabalho no macOS e tornar o comportamento de sistemas mais fácil de inspecionar. Meu trabalho abrange Go, Python, Rust, PHP, TypeScript e configuração de infraestrutura.

## Projetos selecionados

| Projeto | O que oferece |
| --- | --- |
| [Infraestrutura de runners do GitHub](https://github.com/somethingwithproof/github-runners-infra) | Um controlador em Go para runners de job único com escopo de repositório na DigitalOcean, AWS, Google Cloud e Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Um explorador estático para dados de energia solar distribuída da Califórnia, com metodologia e limites explícitos de cobertura/modelagem | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Fluxos de captura no macOS para aplicativos de produtividade, usando AppleScript, Automator e Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Uma CLI interativa em Rust para construir mensagens de Conventional Commits | |
| [Verificação de preço do Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Um plugin para Nagios/Icinga com limites de preço, verificações opcionais de atualização da cotação e retentativas limitadas de requisição | |

O README, o código-fonte e os resultados dos workflows de cada projeto definem seu escopo atual. Recursos experimentais e integrações específicas de plataforma exigem validação própria; um badge não representa garantia de prontidão para produção.

## Outros trabalhos

- **Monitoramento de rede:** [Kadupul](https://github.com/kadupulhq/kadupul), um projeto de monitoramento derivado do Cacti sob a organização `kadupulhq`.
- **Configuração de infraestrutura:** automação para [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) e [firewall de host](https://github.com/somethingwithproof/ansible-collection-firewall), com limites específicos de implementação documentados em cada repositório.
- **Integração com macOS:** [Servidores MCP](https://github.com/somethingwithproof/mcp-servers), o repositório consolidado para integrações de aplicativos.
- **Ferramentas de CI:** [Foundry](https://github.com/somethingwithproof/foundry), um executor de comandos baseado em perfis com planejamento de dependências e logs de execução.

Também trabalho com fluxos de evidências genealógicas e pesquisa de dados de mercado. Esses interesses não implicam conclusões de pesquisa certificadas, desempenho de negociação verificado nem disponibilidade pública de todos os repositórios de pesquisa.

## Relatos de segurança

Siga o `SECURITY.md` do repositório afetado e seu canal privado de relato configurado. Para projetos upstream, use o processo de divulgação do projeto upstream. Evite abrir issues públicas contendo detalhes de vulnerabilidades não divulgadas ou credenciais.
