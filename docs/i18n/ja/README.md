# Thomas Vincent

インフラストラクチャの運用、macOS ワークフローの自動化、およびシステムの挙動を検査しやすくするためのツールを開発しています。Go、Python、Rust、PHP、TypeScript、およびインフラ構成管理にわたる領域に取り組んでいます。

## 主なプロジェクト

| プロジェクト | 概要 |
| --- | --- |
| [GitHub ランナーインフラストラクチャ](https://github.com/somethingwithproof/github-runners-infra) | DigitalOcean、AWS、Google Cloud、および Azure 上でリポジトリ単位の単一ジョブランナーを管理する Go コントローラー | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | カリフォルニア州の分散型太陽光発電データの静的エクスプローラー（手法とカバレッジ・モデリング上の制約を明記） | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | AppleScript、Automator、Alfred を用いた生産性向上アプリ向けの macOS キャプチャワークフロー | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Conventional Commit メッセージを対話的に作成するための Rust 製 CLI | |
| [Bitcoin 価格チェック](https://github.com/somethingwithproof/check_bitcoin_price) | 価格しきい値、オプションの相場鮮度チェック、および上限付きリクエストリトライを備えた Nagios/Icinga プラグイン | |

各プロジェクトの現在の適用範囲は、それぞれの README、ソースコード、およびワークフローの実行結果によって定義されます。実験的な機能やプラットフォーム固有の連携には個別の検証が必要であり、バッジは本番運用対応を保証するものではありません。

## その他の取り組み

- **ネットワーク監視:** [Kadupul](https://github.com/kadupulhq/kadupul) — `kadupulhq` オーガニゼーション配下で開発している Cacti 派生の監視プロジェクトです。
- **インフラ構成管理:** [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb)、[WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise)、および [ホストファイアウォール](https://github.com/somethingwithproof/ansible-collection-firewall) の自動化。実装ごとの制約は各リポジトリに記載しています。
- **macOS 連携:** [MCP サーバー](https://github.com/somethingwithproof/mcp-servers) — アプリケーション連携を統合したリポジトリです。
- **CI ツール:** [Foundry](https://github.com/somethingwithproof/foundry) — 依存関係プランニングと実行ログを備えたプロファイルベースのコマンドランナーです。

また、系譜学的な証拠検証ワークフローや市場データの調査にも取り組んでいます。これらの活動は、認定された研究結論、検証済みの取引実績、またはすべての調査リポジトリの一般公開を意味するものではありません。
