# Thomas Vincent

אני בונה כלים לתפעול תשתיות, אוטומציה של תהליכי עבודה ב-macOS והקלה על בחינת התנהגות מערכות. העבודה שלי משתרעת על Go, Python, Rust, PHP, TypeScript ותצורת תשתיות.

## פרויקטים נבחרים

| פרויקט | מה הוא מספק |
| --- | --- |
| [תשתית רצים של GitHub](https://github.com/somethingwithproof/github-runners-infra) | בקר ב-Go לרצים המיועדים למשימה בודדת ברמת מאגר, על גבי DigitalOcean, AWS, Google Cloud ו-Azure |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | סייר סטטי לנתוני אנרגיה סולארית מבוזרת בקליפורניה, כולל מתודולוגיה ומגבלות כיסוי ומידול מפורשות |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | תהליכי עבודה ללכידת מידע ב-macOS עבור יישומי פרודוקטיביות, באמצעות AppleScript, Automator ו-Alfred |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | כלי CLI אינטראקטיבי ב-Rust לבניית הודעות Conventional Commit |
| [בדיקת מחיר ביטקוין](https://github.com/somethingwithproof/check_bitcoin_price) | תוסף Nagios/Icinga עם ספי מחיר, בדיקות עדכניות ציטוט אופציונליות וניסיונות חוזרים תחומים |

קובץ ה-README, קוד המקור ותוצאות תהליכי העבודה של כל פרויקט מגדירים את ההיקף הנוכחי שלו. תכונות ניסיוניות ואינטגרציות ייעודיות לפלטפורמה דורשות אימות משלהן; תגית (badge) אינה מהווה טענה למוכנות לייצור.

## עבודות נוספות

- **ניטור רשת:** [Kadupul](https://github.com/kadupulhq/kadupul), פרויקט ניטור המבוסס על Cacti תחת הארגון `kadupulhq`.
- **תצורת תשתיות:** אוטומציה של [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) ו[חומת אש של מארח](https://github.com/somethingwithproof/ansible-collection-firewall), כאשר מגבלות ספציפיות למימוש מתועדות בכל מאגר.
- **אינטגרציה עם macOS:** [שרתי MCP](https://github.com/somethingwithproof/mcp-servers), המאגר המאוחד לאינטגרציות עם יישומים.
- **כלי CI:** [Foundry](https://github.com/somethingwithproof/foundry), מריץ פקודות מבוסס פרופילים עם תכנון תלויות ויומני הרצה.

אני עובד גם על תהליכי עבודה לראיות גנאלוגיות ועל מחקר נתוני שוק. תחומי עניין אלה אינם מעידים על מסקנות מחקר מאושרות, ביצועי מסחר מאומתים או זמינות ציבורית של כל מאגר מחקר.

## דיווחי אבטחה

פעלו לפי הקובץ `SECURITY.md` של המאגר הרלוונטי ולפי ערוץ הדיווח הפרטי המוגדר בו. עבור פרויקטי upstream, השתמשו בתהליך הגילוי של פרויקט ה-upstream. הימנעו מפתיחת תקלות ציבוריות הכוללות פרטי פגיעויות שטרם נחשפו או פרטי התחברות.
