# Thomas Vincent

Ana m arụ ngwaọrụ maka ịrụ ọrụ akụrụngwa, ime ka usoro ọrụ macOS na-arụ ọrụ n'akpaghị aka, na ime ka omume sistemụ dị mfe inyocha. Ọrụ m gụnyere Go, Python, Rust, PHP, TypeScript, na nhazi akụrụngwa.

## Ọrụ ndị a họọrọ

| Ọrụ | Ihe ọ na-enye |
| --- | --- |
| [Akụrụngwa runner nke GitHub](https://github.com/somethingwithproof/github-runners-infra) | Controller Go maka runner otu ọrụ dabere n'otu ebe nchekwa gafee DigitalOcean, AWS, Google Cloud, na Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Ngwa nchọgharị static maka data ike anyanwụ e kesara na California, nwere usoro nyocha na oke mkpuchi/mmepụta ụdị doro anya | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Usoro ọrụ njide ozi macOS maka ngwa nrụpụta ọrụ, na-eji AppleScript, Automator, na Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | CLI Rust na-emekọrịta ihe maka iwulite ozi Conventional Commit | |
| [Nnyocha ọnụahịa Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Plugin Nagios/Icinga nwere oke ọnụahịa, nnyocha nhọrọ nke ịdị ọhụrụ nke ọnụahịa, na mgbalị arịrịọ nwere oke | |

README, isi mmalite, na nsonaazụ usoro ọrụ nke ọrụ ọ bụla na-akọwa oke ya ugbu a. Atụmatụ nnwale na njikọta pụrụ iche maka ikpo okwu chọrọ nnyocha nke ha; akara ngosi abụghị nkwupụta njikere mmepụta.

## Ọrụ ndị ọzọ

- **Nlekọta netwọk:** [Kadupul](https://github.com/kadupulhq/kadupul), ọrụ nlekọta sitere na Cacti n'okpuru otu `kadupulhq`.
- **Nhazi akụrụngwa:** Arụmọrụ n'akpaghị aka maka [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), na [firewall nke host](https://github.com/somethingwithproof/ansible-collection-firewall), nwere oke mmejupụta pụrụ iche e dere n'ebe nchekwa nke ọ bụla.
- **Njikọta macOS:** [Sava MCP](https://github.com/somethingwithproof/mcp-servers), ebe nchekwa jikọtara ọnụ maka njikọta ngwa.
- **Ngwaọrụ CI:** [Foundry](https://github.com/somethingwithproof/foundry), ngwa ọsọ iwu dabere na profaịlụ nke nwere atụmatụ ndabere na ndekọ mmezu.

Ana m arụkwa ọrụ na usoro ọrụ ihe akaebe agbụrụ na ọmụmụ na nyocha data ahịa. Mmasị ndị ahụ apụtaghị nkwubi okwu nyocha nwere asambodo, arụmọrụ azụmahịa a kwadoro, ma ọ bụ nnweta ọha nke ebe nchekwa nyocha ọ bụla.

## Akụkọ nchekwa

Soro `SECURITY.md` nke ebe nchekwa metụtara na ọwa akụkọ nzuzo ya e haziri. Maka ọrụ upstream, jiri usoro mkpughe nke ọrụ upstream ahụ. Zere okwu ọha nwere nkọwa adịghị ike nchekwa a na-ekpughebeghị ma ọ bụ nzere.
