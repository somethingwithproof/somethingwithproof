# Thomas Vincent

Ndakha izixhobo zokusebenzisa iziseko zophuhliso, ukwenza iinkqubo zokusebenza ze-macOS zizenzekele, kunye nokwenza ukuziphatha kwenkqubo kube lula ukukuhlola. Umsebenzi wam ubandakanya i-Go, i-Python, i-Rust, i-PHP, i-TypeScript, kunye noqwalaselo lweziseko zophuhliso.

## Iiprojekthi ezikhethiweyo

| Iprojekthi | Oko ikunikezelayo |
| --- | --- |
| [Iziseko zophuhliso zabaqhubi be-GitHub](https://github.com/somethingwithproof/github-runners-infra) | Isilawuli se-Go sabaqhubi bomsebenzi omnye abajoliswe kwi-repository kwi-DigitalOcean, i-AWS, i-Google Cloud, kunye ne-Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Isikhangeli esingaguqukiyo sedatha yamandla elanga asasaziweyo eCalifornia, esinendlela yokusebenza kunye nemida ecacileyo yokugubungela nokwenza imodeli | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Iinkqubo zokusebenza zokufaka ulwazi kwi-macOS zezicelo zemveliso, zisebenzisa i-AppleScript, i-Automator, kunye ne-Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | I-CLI ye-Rust enokusebenzisana yokwakha imiyalezo ye-Conventional Commit | |
| [Uhlolo lwexabiso le-Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Iplagini ye-Nagios/Icinga enemida yexabiso, uhlolo olukhethwayo lokutsha kwexabiso, kunye namalinge okuphinda acele anqunyelweyo | |

I-README yeprojekthi nganye, ikhowudi yomthombo, kunye neziphumo zenkqubo yokusebenza zichaza umda wayo wangoku. Iimpawu zovavanyo kunye nokudityaniswa okukhethekileyo kweqonga kufuna uqinisekiso lwazo; ibheji ayilulo ibango lokulungela ukuvelisa.

## Omunye umsebenzi

- **Ukubeka iliso kwinethiwekhi:** I-[Kadupul](https://github.com/kadupulhq/kadupul), iprojekthi yokubeka iliso ethathwe kwi-Cacti phantsi kombutho we-`kadupulhq`.
- **Uqwalaselo lweziseko zophuhliso:** Ukwenza kuzenzekele kwe-[MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), i-[WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), kunye [ne-firewall yomncedisi](https://github.com/somethingwithproof/ansible-collection-firewall), kunye nemida ekhethekileyo yokumiselwa ebhalwe kwi-repository nganye.
- **Udibaniso lwe-macOS:** [Abancedisi be-MCP](https://github.com/somethingwithproof/mcp-servers), i-repository edibeneyo yodibaniso lwezicelo.
- **Izixhobo ze-CI:** I-[Foundry](https://github.com/somethingwithproof/foundry), umqhubi wemiyalelo osekelwe kwiprofayili onocwangciso lwezinto ezixhomekeke kuzo kunye neelogi zokuqhuba.

Ndikwasebenza kwiinkqubo zokusebenza zobungqina bomnombo kunye nophando lwedatha yemarike. Loo midla ayithethi izigqibo zophando eziqinisekisiweyo, ukusebenza kokurhweba okuqinisekisiweyo, okanye ukufumaneka esidlangalaleni kwayo yonke i-repository yophando.

## Iingxelo zokhuseleko

Landela i-`SECURITY.md` ye-repository echaphazelekayo kunye nejelo layo lokunika ingxelo labucala eliqwalaselweyo. Kwiiprojekthi zomthombo oyintloko, sebenzisa inkqubo yokubhengeza yeprojekthi yomthombo oyintloko. Kuphephe ukuvula imiba yesidlangalala equlethe iinkcukacha zobuthathaka ezingabhengezwanga okanye iinkcukacha zokungena.
