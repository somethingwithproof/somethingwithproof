# Thomas Vincent

Je conçois des outils pour exploiter des infrastructures, automatiser des workflows macOS et rendre le comportement des systèmes plus facile à inspecter. Mon travail couvre Go, Python, Rust, PHP, TypeScript et la configuration d'infrastructure.

## Projets sélectionnés

| Projet | Ce qu'il propose |
| --- | --- |
| [Infrastructure de runners GitHub](https://github.com/somethingwithproof/github-runners-infra) | Un contrôleur Go pour des runners à tâche unique dédiés à un dépôt sur DigitalOcean, AWS, Google Cloud et Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Un explorateur statique des données d'énergie solaire distribuée en Californie, accompagné de la méthodologie et des limites explicites de couverture et de modélisation | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Des workflows de capture macOS pour les applications de productivité, utilisant AppleScript, Automator et Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Une CLI Rust interactive pour rédiger des messages Conventional Commit | |
| [Vérification du cours du Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Un plugin Nagios/Icinga avec seuils de prix, vérifications optionnelles de fraîcheur des cotations et tentatives de requête bornées | |

Le README, le code source et les résultats des workflows de chaque projet définissent son périmètre actuel. Les fonctionnalités expérimentales et les intégrations propres à une plateforme nécessitent leur propre validation ; un badge ne constitue pas une garantie d'aptitude à la production.

## Autres travaux

- **Supervision réseau :** [Kadupul](https://github.com/kadupulhq/kadupul), un projet de supervision dérivé de Cacti hébergé sous l'organisation `kadupulhq`.
- **Configuration d'infrastructure :** automatisation pour [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) et [pare-feu d'hôte](https://github.com/somethingwithproof/ansible-collection-firewall), avec les limites propres à chaque implémentation documentées dans son dépôt respectif.
- **Intégration macOS :** [serveurs MCP](https://github.com/somethingwithproof/mcp-servers), le dépôt consolidé regroupant les intégrations d'applications.
- **Outillage CI :** [Foundry](https://github.com/somethingwithproof/foundry), un exécuteur de commandes basé sur des profils avec planification des dépendances et journaux d'exécution.

Je travaille également sur des workflows de preuves généalogiques et la recherche sur les données de marché. Ces domaines d'intérêt n'impliquent ni conclusions de recherche certifiées, ni performances de trading vérifiées, ni disponibilité publique de chaque dépôt de recherche.

## Signalements de sécurité

Suivez le fichier `SECURITY.md` du dépôt concerné ainsi que son canal privé de signalement configuré. Pour les projets en amont, utilisez leur propre procédure de divulgation. Évitez d'ouvrir des issues publiques contenant des détails de vulnérabilités non divulguées ou des identifiants.
