# Thomas Vincent

Ek bou nutsmiddels vir die bedryf van infrastruktuur, die outomatisering van macOS-werkvloeie en om stelselgedrag makliker inspekteerbaar te maak. My werk strek oor Go, Python, Rust, PHP, TypeScript en infrastruktuurkonfigurasie.

## Geselekteerde projekte

| Projek | Wat dit bied |
| --- | --- |
| [GitHub-loperinfrastruktuur](https://github.com/somethingwithproof/github-runners-infra) | 'n Go-beheerder vir bewaarplek-gekoppelde enkeltaak-lopers oor DigitalOcean, AWS, Google Cloud en Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | 'n Statiese verkenner vir Kaliforniese verspreide sondata, met metodologie en eksplisiete dekkings-/modelleringsgrense | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | macOS-vasleggingswerkvloeie vir produktiwiteitstoepassings met behulp van AppleScript, Automator en Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | 'n Interaktiewe Rust-CLI vir die saamstel van Conventional Commit-boodskappe | |
| [Bitcoin-pryskontrole](https://github.com/somethingwithproof/check_bitcoin_price) | 'n Nagios/Icinga-inprop met prysdrempels, opsionele kwotasie-varsheidskontroles en begrensde herpogings vir versoeke | |

Elke projek se README, bronkode en werkvloei-resultate definieer sy huidige omvang. Eksperimentele funksies en platformspesifieke integrasies vereis hul eie validering; 'n kenteken is nie 'n bewering van produksiegereedheid nie.

## Ander werk

- **Netwerkmonitering:** [Kadupul](https://github.com/kadupulhq/kadupul), 'n Cacti-afgeleide moniteringsprojek onder die `kadupulhq`-organisasie.
- **Infrastruktuurkonfigurasie:** [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb)-, [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise)- en [gasheer-brandmuur](https://github.com/somethingwithproof/ansible-collection-firewall)-outomatisering, met implementeringsspesifieke beperkings gedokumenteer in elke bewaarplek.
- **macOS-integrasie:** [MCP-bedieners](https://github.com/somethingwithproof/mcp-servers), die gekonsolideerde bewaarplek vir toepassingsintegrasies.
- **CI-nutsmiddels:** [Foundry](https://github.com/somethingwithproof/foundry), 'n profielgebaseerde opdraguitvoerder met afhanklikheidsbeplanning en uitvoeringslogboeke.

Ek werk ook aan genealogiese bewyswerkvloeie en markdatanavorsing. Daardie belangstellings impliseer nie gesertifiseerde navorsingsgevolgtrekkings, geverifieerde handelsprestasie of openbare beskikbaarheid van elke navorsingsbewaarplek nie.

## Sekuriteitsverslae

Volg die betrokke bewaarplek se `SECURITY.md` en sy gekonfigureerde private aanmeldingskanaal. Vir stroomop-projekte, gebruik die stroomop-projek se openbaarmakingsproses. Vermy openbare kwessies wat ongeopenbaarde kwesbaarheidsbesonderhede of aanmeldbewyse bevat.
