# Thomas Vincent

我致力於建置用於維運基礎架構、自動化 macOS 工作流程，以及讓系統行為更易於檢視的工具。我的工作涵蓋 Go、Python、Rust、PHP、TypeScript 與基礎架構設定。

## 精選專案

| 專案 | 功能簡介 |
| --- | --- |
| [GitHub runner 基礎架構](https://github.com/somethingwithproof/github-runners-infra) | 適用於 DigitalOcean、AWS、Google Cloud 與 Azure，支援單一工作且限定於儲存庫範圍之 runner 的 Go 控制器 | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | 加州分散式太陽能資料的靜態探索工具，附帶方法論以及明確的涵蓋範圍與模型限制說明 | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | 使用 AppleScript、Automator 與 Alfred 打造的生產力應用程式 macOS 資訊擷取工作流程 | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | 用於建立 Conventional Commit 提交訊息的互動式 Rust CLI | |
| [比特幣價格檢查](https://github.com/somethingwithproof/check_bitcoin_price) | 具備價格門檻、選用報價新鮮度檢查與有界請求重試機制的 Nagios／Icinga 外掛程式 | |

各專案的 README、原始碼與工作流程執行結果界定了其目前的適用範圍。實驗性功能與特定平台整合皆須另行驗證；徽章並非正式環境就緒的保證。

## 其他作品

- **網路監控：** [Kadupul](https://github.com/kadupulhq/kadupul)，隸屬於 `kadupulhq` 組織、衍生自 Cacti 的監控專案。
- **基礎架構設定：** [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb)、[WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) 與[主機防火牆](https://github.com/somethingwithproof/ansible-collection-firewall)自動化工具，各自實作的限制均記錄於對應儲存庫中。
- **macOS 整合：** [MCP 伺服器](https://github.com/somethingwithproof/mcp-servers)，整合各類應用程式介接的彙整儲存庫。
- **CI 工具：** [Foundry](https://github.com/somethingwithproof/foundry)，支援設定檔（profile）的指令執行工具，具備相依規劃與執行日誌功能。

我也投入族譜證據工作流程與市場資料研究。這些研究領域不代表經認證的研究結論、經驗證的交易績效，亦不代表所有研究儲存庫皆對外公開。

## 安全性回報

請遵循受影響儲存庫的 `SECURITY.md` 及其設定的私密回報管道。針對上游專案，請遵循該上游專案的揭露流程。請避免在公開的 issue 中揭露未公開的漏洞細節或認證資訊。
