# Thomas Vincent

Gumagawa ako ng mga tool para sa pagpapatakbo ng imprastraktura, pag-automate ng mga workflow sa macOS, at pagpapadali sa pagsusuri ng gawi ng sistema. Saklaw ng aking trabaho ang Go, Python, Rust, PHP, TypeScript, at konfigurasyon ng imprastraktura.

## Mga piling proyekto

| Proyekto | Ang ibinibigay nito |
| --- | --- |
| [Imprastraktura ng GitHub runner](https://github.com/somethingwithproof/github-runners-infra) | Isang Go controller para sa mga runner na nakatuon sa repository at nagpapatakbo ng iisang job sa DigitalOcean, AWS, Google Cloud, at Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Isang static explorer para sa datos ng distributed solar sa California, na may metodolohiya at malinaw na mga limitasyon sa saklaw/pagmomodelo | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Mga workflow sa pagkuha ng tala sa macOS para sa mga productivity application, gamit ang AppleScript, Automator, at Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Isang interactive na Rust CLI para sa pagbuo ng mga mensaheng Conventional Commit | |
| [Pagsusuri ng presyo ng Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Isang plugin ng Nagios/Icinga na may mga threshold sa presyo, opsyonal na pagsusuri ng pagiging bago ng quote, at may hangganang muling pagsubok ng request | |

Tinutukoy ng README, source, at mga resulta ng workflow ng bawat proyekto ang kasalukuyang saklaw nito. Ang mga eksperimental na feature at mga integrasyong partikular sa platform ay nangangailangan ng sariling pagpapatunay; ang isang badge ay hindi pag-aangkin ng kahandaan sa produksiyon.

## Iba pang gawain

- **Pagsubaybay sa network:** [Kadupul](https://github.com/kadupulhq/kadupul), isang proyektong pangsubaybay na hango sa Cacti sa ilalim ng organisasyong `kadupulhq`.
- **Konfigurasyon ng imprastraktura:** Awtomasyon ng [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise), at [host firewall](https://github.com/somethingwithproof/ansible-collection-firewall), na may mga limitasyong partikular sa implementasyon na nakadokumento sa bawat repository.
- **Integrasyon sa macOS:** [Mga MCP server](https://github.com/somethingwithproof/mcp-servers), ang pinagsamang repository para sa mga integrasyon ng application.
- **Mga tool sa CI:** [Foundry](https://github.com/somethingwithproof/foundry), isang profile-based command runner na may pagpaplano ng dependency at mga log ng pagpapatakbo.

Nagtatrabaho rin ako sa mga workflow para sa ebidensyang pang-genealogy at pananaliksik sa datos ng merkado. Ang mga interes na iyon ay hindi nagpapahiwatig ng mga sertipikadong konklusyon sa pananaliksik, naberipikang pagganap sa trading, o pampublikong pagkakaroon ng bawat repository ng pananaliksik.

## Mga ulat sa seguridad

Sundin ang `SECURITY.md` ng apektadong repository at ang naka-configure nitong pribadong channel sa pag-uulat. Para sa mga upstream na proyekto, gamitin ang proseso ng pagbubunyag ng upstream na proyekto. Iwasan ang mga pampublikong issue na naglalaman ng mga hindi pa nabubunyag na detalye ng kahinaan o mga kredensyal.
