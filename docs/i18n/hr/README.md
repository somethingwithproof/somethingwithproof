# Thomas Vincent

Izrađujem alate za upravljanje infrastrukturom, automatizaciju macOS tijekova rada i jednostavniji nadzor ponašanja sustava. Moj rad obuhvaća Go, Python, Rust, PHP, TypeScript i konfiguraciju infrastrukture.

## Odabrani projekti

| Projekt | Što pruža |
| --- | --- |
| [Infrastruktura za GitHub runnere](https://github.com/somethingwithproof/github-runners-infra) | Go upravljački servis za jednokratne runnere vezane uz repozitorij na platformama DigitalOcean, AWS, Google Cloud i Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Statički preglednik podataka o distribuiranoj solarnoj energiji u Kaliforniji s metodologijom i izričitim ograničenjima pokrivenosti i modeliranja | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | macOS tijekovi rada za brzo hvatanje zadataka u aplikacijama za produktivnost uz AppleScript, Automator i Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Interaktivni Rust CLI alat za oblikovanje poruka prema specifikaciji Conventional Commits | |
| [Provjera cijene Bitcoina](https://github.com/somethingwithproof/check_bitcoin_price) | Nagios/Icinga dodatak s cjenovnim pragovima, neobaveznim provjerama svježine kotacija i ograničenim brojem ponovljenih zahtjeva | |

Datoteka README, izvorni kod i rezultati tijekova rada svakog projekta određuju njegov trenutačni opseg. Eksperimentalne značajke i integracije specifične za platformu zahtijevaju vlastitu provjeru; značka ne predstavlja jamstvo spremnosti za produkciju.

## Ostali radovi

- **Nadzor mreže:** [Kadupul](https://github.com/kadupulhq/kadupul), projekt za nadzor mreže proizašao iz Cactija u organizaciji `kadupulhq`.
- **Konfiguracija infrastrukture:** automatizacija za [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) i [vatrozid poslužitelja](https://github.com/somethingwithproof/ansible-collection-firewall), uz ograničenja specifična za implementaciju dokumentirana u svakom repozitoriju.
- **macOS integracija:** [MCP poslužitelji](https://github.com/somethingwithproof/mcp-servers), objedinjeni repozitorij za integracije aplikacija.
- **CI alati:** [Foundry](https://github.com/somethingwithproof/foundry), pokretač naredbi temeljen na profilima s planiranjem ovisnosti i zapisnicima izvođenja.

Također radim na tijekovima rada za genealoške dokaze i istraživanju tržišnih podataka. Ta područja ne podrazumijevaju certificirane istraživačke zaključke, provjerenu uspješnost trgovanja niti javnu dostupnost svakog istraživačkog repozitorija.

## Sigurnosna izvješća

Slijedite datoteku `SECURITY.md` zahvaćenog repozitorija i njegov postavljeni privatni kanal za prijavu. Za uzvodne projekte koristite postupak otkrivanja ranjivosti tog projekta. Izbjegavajte javne prijave koje sadrže neobjavljene pojedinosti o ranjivostima ili vjerodajnice.
