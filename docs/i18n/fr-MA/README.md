# Thomas Vincent

Je développe des outils pour l'exploitation d'infrastructures, l'automatisation de workflows macOS et l'observabilité du comportement des systèmes. Mes travaux couvrent Go, Python, Rust, PHP, TypeScript ainsi que la configuration d'infrastructure.

## Projets sélectionnés

| Projet | Ce qu'il propose |
| --- | --- |
| [Infrastructure de runners GitHub](https://github.com/somethingwithproof/github-runners-infra) | Un contrôleur Go pour des runners à tâche unique dédiés à un dépôt sur DigitalOcean, AWS, Google Cloud et Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Un explorateur statique des données solaires distribuées de Californie, accompagné de sa méthodologie et des limites explicites de couverture et de modélisation | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Des workflows de capture sur macOS pour les applications de productivité, reposant sur AppleScript, Automator et Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Une CLI interactive en Rust pour composer des messages Conventional Commit | |
| [Contrôle du prix du Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Un plugin Nagios/Icinga doté de seuils de prix, de vérifications optionnelles de fraîcheur des cotations et de tentatives de requête bornées | |

Le README, le code source et les résultats de workflows de chaque projet définissent son périmètre actuel. Les fonctionnalités expérimentales et les intégrations spécifiques à une plateforme requièrent leur propre validation ; un badge ne constitue pas une garantie de mise en production.

## Autres travaux

- **Supervision réseau :** [Kadupul](https://github.com/kadupulhq/kadupul), un projet de supervision dérivé de Cacti au sein de l'organisation `kadupulhq`.
- **Configuration d'infrastructure :** automatisation pour [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) et [pare-feu d'hôte](https://github.com/somethingwithproof/ansible-collection-firewall), avec les limites propres à chaque implémentation documentées dans le dépôt correspondant.
- **Intégration macOS :** [Serveurs MCP](https://github.com/somethingwithproof/mcp-servers), le dépôt consolidé regroupant les intégrations applicatives.
- **Outillage CI :** [Foundry](https://github.com/somethingwithproof/foundry), un exécuteur de commandes basé sur des profils avec planification des dépendances et journaux d'exécution.

Je travaille également sur des workflows de preuves généalogiques et la recherche sur les données de marché. Ces domaines d'intérêt n'impliquent ni conclusions de recherche certifiées, ni performances de trading vérifiées, ni disponibilité publique de tous les dépôts de recherche.

## Signalements de sécurité

Suivez le fichier `SECURITY.md` du dépôt concerné ainsi que son canal privé de signalement configuré. Pour les projets en amont, utilisez le processus de divulgation du projet amont. Évitez d'ouvrir des tickets publics contenant des détails de vulnérabilités non divulguées ou des identifiants.
