# Thomas Vincent

Я создаю инструменты для эксплуатации инфраструктуры, автоматизации рабочих процессов macOS и повышения прозрачности поведения систем. Мои проекты охватывают Go, Python, Rust, PHP, TypeScript и управление конфигурацией инфраструктуры.

## Избранные проекты

| Проект | Описание |
| --- | --- |
| [Инфраструктура раннеров GitHub](https://github.com/somethingwithproof/github-runners-infra) | Контроллер на Go для одноразовых раннеров уровня репозитория в DigitalOcean, AWS, Google Cloud и Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Статический обозреватель данных о распределённой солнечной энергетике Калифорнии с описанием методологии и явными ограничениями охвата и моделирования | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | Рабочие процессы сбора задач в macOS для приложений продуктивности с использованием AppleScript, Automator и Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Интерактивный CLI-инструмент на Rust для составления сообщений коммитов в формате Conventional Commits | |
| [Проверка цены Bitcoin](https://github.com/somethingwithproof/check_bitcoin_price) | Плагин Nagios/Icinga с пороговыми значениями цены, опциональной проверкой актуальности котировок и ограниченным числом повторных запросов | |

Текущие рамки каждого проекта определяются его файлом README, исходным кодом и результатами рабочих процессов. Экспериментальные функции и интеграции для конкретных платформ требуют отдельной проверки; бейдж не является заявлением о готовности к промышленной эксплуатации.

## Другие проекты

- **Мониторинг сетей:** [Kadupul](https://github.com/kadupulhq/kadupul) — проект мониторинга на основе Cacti в организации `kadupulhq`.
- **Конфигурация инфраструктуры:** автоматизация [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) и [межсетевого экрана хоста](https://github.com/somethingwithproof/ansible-collection-firewall) с ограничениями конкретной реализации, задокументированными в каждом репозитории.
- **Интеграция с macOS:** [MCP-серверы](https://github.com/somethingwithproof/mcp-servers) — единый репозиторий для интеграций с приложениями.
- **Инструменты CI:** [Foundry](https://github.com/somethingwithproof/foundry) — инструмент запуска команд на основе профилей с планированием зависимостей и журналами выполнения.

Я также занимаюсь рабочими процессами анализа генеалогических свидетельств и исследованием рыночных данных. Эти направления не подразумевают сертифицированных исследовательских заключений, подтверждённых торговых результатов или публичной доступности каждого исследовательского репозитория.

## Сообщения об уязвимостях

Следуйте инструкциям в файле `SECURITY.md` затронутого репозитория и используйте настроенный закрытый канал для сообщений. Для проектов upstream используйте их собственный процесс раскрытия уязвимостей. Не публикуйте в открытых задачах (issues) нераскрытые сведения об уязвимостях или учётные данные.
