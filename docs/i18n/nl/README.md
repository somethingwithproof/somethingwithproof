# Thomas Vincent

Ik bouw tools voor het beheren van infrastructuur, het automatiseren van macOS-workflows en het inzichtelijker maken van systeemgedrag. Mijn werk omvat Go, Python, Rust, PHP, TypeScript en infrastructuurconfiguratie.

## Geselecteerde projecten

| Project | Wat het biedt |
| --- | --- |
| [GitHub-runnerinfrastructuur](https://github.com/somethingwithproof/github-runners-infra) | Een Go-controller voor repository-specifieke runners voor één taak tegelijk op DigitalOcean, AWS, Google Cloud en Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Een statische verkenner voor gegevens over gedistribueerde zonne-energie in Californië, met methodologie en expliciete dekkings- en modelleringsgrenzen | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | macOS-vastlegworkflows voor productiviteitsapplicaties met behulp van AppleScript, Automator en Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Een interactieve Rust-CLI voor het opstellen van Conventional Commit-berichten | |
| [Bitcoin-prijscontrole](https://github.com/somethingwithproof/check_bitcoin_price) | Een Nagios/Icinga-plug-in met prijsdrempels, optionele controles op koersactualiteit en begrensde herhaalpogingen voor aanvragen | |

De README, broncode en workflowresultaten van elk project bepalen de huidige reikwijdte. Experimentele functies en platformspecifieke integraties vereisen hun eigen validatie; een badge is geen claim van productiegeschiktheid.

## Overig werk

- **Netwerkmonitoring:** [Kadupul](https://github.com/kadupulhq/kadupul), een van Cacti afgeleid monitoringproject onder de `kadupulhq`-organisatie.
- **Infrastructuurconfiguratie:** automatisering voor [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) en [host-firewall](https://github.com/somethingwithproof/ansible-collection-firewall), waarbij implementatiespecifieke beperkingen in elke repository zijn gedocumenteerd.
- **macOS-integratie:** [MCP-servers](https://github.com/somethingwithproof/mcp-servers), de geconsolideerde repository voor applicatie-integraties.
- **CI-tooling:** [Foundry](https://github.com/somethingwithproof/foundry), een profielgebaseerde commando-uitvoerder met afhankelijkheidsplanning en uitvoeringslogs.

Ik werk ook aan workflows voor genealogisch bewijsmateriaal en marktdataonderzoek. Die interesses impliceren geen gecertificeerde onderzoeksconclusies, geverifieerde handelsprestaties of openbare beschikbaarheid van elke onderzoeksrepository.

## Beveiligingsmeldingen

Volg de `SECURITY.md` van de betreffende repository en het daar geconfigureerde privémeldingskanaal. Gebruik voor upstream-projecten het meldingsproces van het upstream-project. Vermijd openbare issues met niet-openbaar gemaakte kwetsbaarheidsdetails of inloggegevens.
