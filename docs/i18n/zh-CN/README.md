# Thomas Vincent

我构建用于运维基础设施、自动化 macOS 工作流以及让系统行为更易于检查的工具。我的工作涵盖 Go、Python、Rust、PHP、TypeScript 和基础设施配置。

## 精选项目

| 项目 | 功能说明 |
| --- | --- |
| [GitHub 运行器基础设施](https://github.com/somethingwithproof/github-runners-infra) | 适用于 DigitalOcean、AWS、Google Cloud 和 Azure 的仓库级单任务运行器 Go 控制器 | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | 加利福尼亚州分布式太阳能数据的静态浏览器，包含方法论及明确的覆盖范围与建模限制 | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | 基于 AppleScript、Automator 和 Alfred 的 macOS 效率应用快速捕获工作流 | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | 用于构建 Conventional Commit 提交信息的交互式 Rust 命令行工具 | |
| [比特币价格检查](https://github.com/somethingwithproof/check_bitcoin_price) | 支持价格阈值、可选行情时效性检查和有限请求重试的 Nagios/Icinga 插件 | |

每个项目的 README、源代码和工作流结果定义了其当前范围。实验性功能和特定于平台的集成需要单独验证；徽章并不代表生产就绪声明。

## 其他工作

- **网络监控：** [Kadupul](https://github.com/kadupulhq/kadupul)，`kadupulhq` 组织下基于 Cacti 衍生的监控项目。
- **基础设施配置：** [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb)、[WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) 和[主机防火墙](https://github.com/somethingwithproof/ansible-collection-firewall)自动化，各仓库中均记录了特定于实现的限制。
- **macOS 集成：** [MCP 服务器](https://github.com/somethingwithproof/mcp-servers)，用于应用集成的统一仓库。
- **CI 工具：** [Foundry](https://github.com/somethingwithproof/foundry)，支持依赖规划和执行日志的基于配置文件的命令运行器。

我也从事家谱证据工作流和市场数据研究。这些方向并不意味着经认证的研究结论、经验证的交易表现，或每个研究仓库均对外公开。
