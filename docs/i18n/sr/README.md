# Thomas Vincent

Правим алате за управљање инфраструктуром, аутоматизацију macOS токова рада и лакши преглед понашања система. Мој рад обухвата Go, Python, Rust, PHP, TypeScript и конфигурацију инфраструктуре.

## Одабрани пројекти

| Пројекат | Шта пружа |
| --- | --- |
| [Инфраструктура за GitHub ранере](https://github.com/somethingwithproof/github-runners-infra) | Go контролер за једнократне ранере везане за репозиторијум на платформама DigitalOcean, AWS, Google Cloud и Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | Статички прегледач података о дистрибуираној соларној енергији у Калифорнији са методологијом и јасно наведеним ограничењима покривености и моделовања | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | macOS токови рада за брзо бележење задатака у апликацијама за продуктивност помоћу AppleScript, Automator и Alfred алата | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | Интерактивни Rust CLI алат за састављање Conventional Commit порука | |
| [Провера цене Биткоина](https://github.com/somethingwithproof/check_bitcoin_price) | Nagios/Icinga додатак са ценовним праговима, опционим проверама свежине котација и ограниченим бројем поновних захтева | |

Датотека README, изворни код и резултати токова рада сваког пројекта дефинишу његов тренутни обим. Експерименталне функције и интеграције специфичне за платформу захтевају засебну проверу; беџ није тврдња о спремности за продукцију.

## Остали радови

- **Надзор мреже:** [Kadupul](https://github.com/kadupulhq/kadupul), пројекат за надзор мреже заснован на Cacti платформи у организацији `kadupulhq`.
- **Конфигурација инфраструктуре:** аутоматизација за [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) и [заштитни зид хоста](https://github.com/somethingwithproof/ansible-collection-firewall), са специфичним ограничењима имплементације документованим у сваком репозиторијуму.
- **macOS интеграција:** [MCP сервери](https://github.com/somethingwithproof/mcp-servers), обједињени репозиторијум за интеграције апликација.
- **CI алати:** [Foundry](https://github.com/somethingwithproof/foundry), покретач команди заснован на профилима са планирањем зависности и дневницима извршавања.

Такође радим на токовима рада за генеалошке доказе и истраживању тржишних података. Та интересовања не подразумевају сертификоване истраживачке закључке, верификоване резултате трговања нити јавну доступност сваког истраживачког репозиторијума.

## Безбедносни извештаји

Пратите датотеку `SECURITY.md` погођеног репозиторијума и његов подешени приватни канал за пријаву. За узводне пројекте користите њихов процес откривања рањивости. Избегавајте јавне пријаве које садрже необјављене детаље рањивости или акредитиве.
