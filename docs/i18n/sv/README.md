# Thomas Vincent

Jag bygger verktyg för infrastrukturdrift, automatisering av macOS-arbetsflöden och för att göra systembeteenden lättare att inspektera. Mitt arbete spänner över Go, Python, Rust, PHP, TypeScript och infrastrukturkonfiguration.

## Utvalda projekt

| Projekt | Vad det erbjuder |
| --- | --- |
| [Infrastruktur för GitHub-runners](https://github.com/somethingwithproof/github-runners-infra) | En Go-kontroller för arkivspecifika engångs-runners över DigitalOcean, AWS, Google Cloud och Azure | |
| [California Solar Atlas](https://github.com/somethingwithproof/california-solar-atlas) | En statisk utforskare för data om distribuerad solenergi i Kalifornien, med metodik samt tydliga täcknings- och modelleringsbegränsningar | |
| [MacGTD](https://github.com/somethingwithproof/MacGTD) | macOS-arbetsflöden för snabb insamling till produktivitetsappar med hjälp av AppleScript, Automator och Alfred | |
| [CommitKit](https://github.com/somethingwithproof/commitkit-rust) | En interaktiv Rust-CLI för att skapa Conventional Commit-meddelanden | |
| [Bitcoin-priskontroll](https://github.com/somethingwithproof/check_bitcoin_price) | Ett Nagios/Icinga-insticksprogram med priströsklar, valfri kontroll av prisaktualitet och begränsade omförsök för förfrågningar | |

Varje projekts README, källkod och arbetsflödesresultat definierar dess aktuella omfattning. Experimentella funktioner och plattformsspecifika integrationer kräver egen validering; ett märke är ingen garanti om produktionsmognad.

## Övrigt arbete

- **Nätverksövervakning:** [Kadupul](https://github.com/kadupulhq/kadupul), ett Cacti-baserat övervakningsprojekt under organisationen `kadupulhq`.
- **Infrastrukturkonfiguration:** Automatisering av [MariaDB](https://github.com/somethingwithproof/ansible-role-mariadb), [WordPress](https://github.com/somethingwithproof/ansible-wordpress-enterprise) och [värdbrandvägg](https://github.com/somethingwithproof/ansible-collection-firewall), med implementeringsspecifika begränsningar dokumenterade i respektive arkiv.
- **macOS-integration:** [MCP-servrar](https://github.com/somethingwithproof/mcp-servers), det samlade arkivet för applikationsintegrationer.
- **CI-verktyg:** [Foundry](https://github.com/somethingwithproof/foundry), en profilbaserad kommandokörare med beroendeplanering och körningsloggar.

Jag arbetar också med arbetsflöden för genealogisk bevisföring och marknadsdataforskning. Dessa intressen innebär inte certifierade forskningsresultat, verifierad handelsavkastning eller att varje forskningsarkiv är publikt tillgängligt.
